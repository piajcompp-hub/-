# 第1章 成功は「技術」である

## この章のゴール
成功を「才能・運」ではなく「再現できる手順」として捉え直し、現在地を把握する。

## 1. 読む

### 1-1. 成功を技術として扱う
才能は変えられませんが、**手順は学べます**。成功する人に共通するのは次の3つです。

1. **目標が具体的**（いつまでに・何を・どれだけ）
2. **小さな行動を毎日続けている**
3. **うまくいかなかったとき、やり方を修正する**

この講座はこの3つを練習する場です。

### 1-2. 思考→行動→結果のつながり
```
思い込み（考え方） → 感情 → 行動 → 結果 → （結果が思い込みを強化）
```
「どうせ無理」と思えば行動が減り、結果が出ず、「やっぱり無理」と確認してしまいます。
逆に、**小さな行動で小さな結果を作る**と、思い込みが書き換わります。

### 1-3. 3つの基本原則
- **原則1：自分で決める** — 他人や環境のせいにしない。決められる範囲に集中する
- **原則2：小さく始める** — 5分でできる行動に分解する
- **原則3：記録する** — 書かないと、成長が見えず続かない

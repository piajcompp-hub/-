# 第5章 AIで発信を作る

## この章のゴール
AIを「下書きを作る道具」として使い、自分の言葉で発信コンテンツを作れるようになる。

## 1. 読む

### 1-1. AIの役割分担
| 人がやること | AIに任せること |
|---|---|
| 伝えたいこと・体験・意見を決める | 構成案づくり・下書き・言い換え |
| 事実の確認・最終判断 | 誤字チェック・要約・アイデア出し |
| 自分らしい言葉への仕上げ | 長文の整理 |

**AIの出力は必ず自分で読み、事実確認をして、自分の言葉に直してから公開します。**
AIは間違うことがあります。数字・固有名詞・法律や医療の情報は特に注意してください。

### 1-2. 良い指示（プロンプト）の型
```
【役割】あなたは＿＿＿の編集者です。
【目的】＿＿＿のための文章を作ります。
【読者】＿＿＿（年齢・悩み）
【内容】以下の私の体験を元にしてください：＿＿＿
【形式】＿＿＿文字、見出し付き、やさしい口調
【制約】誇大な表現や断定は避ける
```

### 1-3. 使えるプロンプト例

**例A：記事の構成案**
> 以下の体験を元に、読者が共感して行動したくなるブログ記事の見出し構成を5案出してください。読者は＿＿＿で悩む＿＿＿です。体験：＿＿＿

**例B：下書きの添削**
> 以下の文章を、意味を変えずに読みやすく直してください。長い文は分け、専門用語はやさしい言葉にしてください。＿＿＿

**例C：1つの体験からSNS投稿を量産**
> 以下の体験から、SNS用の短い投稿を5本作ってください。それぞれ違う切り口で、各140字以内。＿＿＿

**例D：自分の文体に寄せる**
> 以下は私が書いた文章です。この文体の特徴を分析し、次の内容をその文体で書いてください。＿＿＿

### 1-4. 公開前の5つのチェック
1. 事実・数字は正しいか
2. 他の文章の丸写しになっていないか
3. 自分の体験・意見が入っているか
4. 「必ず儲かる」などの誇大表現はないか
5. 読者に1つ、具体的に役立つ内容があるか

## 2. ワーク

### ワーク5-A：プロンプトを3つ作る
第4章の商品の一文をもとに、1-2の型で以下を作ってください。
- ブログ記事の構成案
- SNS投稿5本
- 自己紹介文

### ワーク5-B：1本の記事を完成させる
1. 自分の体験を箇条書き（5〜10行）
2. AIで構成案を作る
3. 下書きを作らせる
4. **自分の言葉で2割以上書き換える**
5. 5つのチェックを通す

## 3. 今週の行動
- 記事またはSNS投稿を、**最低3本**公開する（非公開でも可。まず書き終えること）
- 投稿ごとに「何を直したか」を1行メモする

# 成功思考実践講座【サポート無し版】 はじめに

ご購入ありがとうございます。この講座は、**自分のペースで、自分で実践する**ための教材です。

## この講座でできること
- 成功思考の基本を理解し、毎日の行動に落とし込む
- 自分の経験を言語化し、「誰に何を提供するか」を決める
- AIを使って発信コンテンツを作る
- Kindle出版の基礎を知る
- 最初の30日の行動計画を作る

## この講座でできないこと
- 個別の質問対応・添削・相談（サポート無し版のため）
- 成果の保証（結果には個人差があります）

## 進め方
1. 1章ずつ、順番に進めてください（目安：週1章、全8章で約2ヶ月）
2. 各章は **「読む → ワーク → 今週の行動 → チェック」** の4ステップです
3. ワークは必ず**紙かノートに書き出して**ください。読むだけでは変わりません
4. 次の章へ進む条件は「チェックリストが全て埋まったこと」です

## 準備するもの
- ノート（またはメモアプリ）
- 毎日15〜30分の時間
- AIチャットツール（第5章以降で使用）

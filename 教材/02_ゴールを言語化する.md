# 第2章 ゴールを言語化する

## この章のゴール
漠然とした願いを、「期限・数字・理由」のある目標に変える。

## 1. 読む

### 1-1. 「願い」と「目標」は違う
- 願い：「収入を増やしたい」「自信をつけたい」
- 目標：「**3ヶ月後までに**、自分の経験を商品化した**サービス案を1つ**完成させる」

目標には必ず **期限・測れる数字・自分がコントロールできる行動** を入れます。

### 1-2. 目標は2種類立てる
- **結果目標**：最終的に得たい状態（コントロールしにくい）
- **行動目標**：毎週・毎日やること（100%自分で決められる）

結果目標だけだと、結果が出ない間に挫折します。**行動目標を主役**にしてください。

### 1-3. 「なぜ」が続ける力になる
目標の理由が弱いと、忙しい日に負けます。「なぜそれが必要か」を3回掘り下げます。

## 2. ワーク

### ワーク2-A：理想の状態を書く
1年後、どんな毎日を送っていたいですか？ 仕事・お金・時間・人間関係・健康の5分野で、
それぞれ2〜3行で具体的に書いてください。

### ワーク2-B：目標設定シート
| 項目 | 記入 |
|---|---|
| 1年後の結果目標 | |
| 3ヶ月後の結果目標（期限つき） | |
| そのための週の行動目標（回数・時間） | |
| 毎日の最小行動（5分でできること） | |

### ワーク2-C：なぜを3回掘る
目標：＿＿＿＿＿＿＿＿
- なぜ、それが欲しい？ → ＿＿＿＿
- なぜ、それが大切？ → ＿＿＿＿
- なぜ、それでなければならない？ → ＿＿＿＿

最後の答えを**目標シートの一番上**に書いて、毎朝見える場所に貼ってください。

## 3. 今週の行動
- 目標シートをスマホで撮影し、待ち受けに設定する
- 毎日、行動目標が実行できたかを記録する
- 週末に「できた回数／予定回数」を計算する

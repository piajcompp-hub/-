# 人生反撃の実務マニュアル
### AIを相棒に、自分の経験をKindle・公式LINE・Zoom説明会につなげる13の実践ステップ

## はじめに

ご購入いただき、ありがとうございます。ハセジュンです。

私は50歳のとき、事業に失敗して6,000万円を失いました。
時給850円の現場から再出発し、1年で事業を安定させ、63歳で資産1億5,000万円まで立て直しました。

その過程で分かったのは、**経験は、形にしなければ誰にも届かない**ということです。
そして、形にするための手順は、才能ではなく**技術**として学べます。

本書は、あなたの経験を

```
Kindle（入口） → 公式LINE（信頼） → Zoom説明会（相談）
```

という「仕組み」につなげるための**実務マニュアル**です。

## 本書の特長

- **考えるための本ではなく、手を動かす手順書です。** 各章で、そのまま手元に残る「成果物」を1つずつ完成させます。
- **本書だけで完結します。** 上位講座に申し込まなくても、13の成果物はすべて本書だけで作れるように作っています。
- **AIは補助輪です。** 書くのはあなた。AIは、あなたの体験を引き出し、整える役です。

## 本書でできないこと

- 個別の質問対応・添削・相談（サポート無し版のため）
- 収入や成果の保証（結果には個人差があります）

## 本書の進め方

1. **第1章から順番に**進めてください。前の章の成果物を、次の章で使います。
2. 各章は **「読む → ワーク → 成果物 → クリア条件」** の流れです。
3. クリア条件を満たしたら、次の章へ進みます。
4. 成果物は、ノート・Googleドキュメント・スプレッドシートなど、**あとで見返せる場所**に保存してください。

> 💡 **最短ルート**
> まず形にしたい方は、**第1章 → 第3章 → 第4章 → 第6章**の順で「Kindleを1冊出す」ことを先に目指してください。公式LINE（第7〜8章）と説明会（第9章）は、そのあとで構いません。

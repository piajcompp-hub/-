# 第5章 表紙・タイトル・紹介文・価格

## 1. 読者の指が止まる「表紙とタイトル」の法則

Kindle出版やBrain販売では、どれほど中身が良くても、表紙とタイトルで「自分に関係がある本だ」と一瞬で伝わらなければ、なかなかクリックされません。

毎日たくさんの情報に触れている読者は、**最初の3秒**で「読むか、スルーするか」を判断します。
読者が見るのは、次の順番です。

```
① 表紙（サムネイル）→ ② タイトル → ③ 紹介文 → ④ 価格
```

この章では、誇大広告に頼らず、本当に悩んでいる読者の心にまっすぐ届く「本の顔」の作り方を解説します。

## 2. タイトル決めの3つの鉄則

タイトルは**「メインタイトル＋サブタイトル」の2段**で考えます。

1. **ターゲットを明確にする**
   誰に向けた本なのか、タイトルを見ただけで1秒で分かるようにする。
   （例：「50歳・資産ゼロ」「中高年のためのAI副業」など）
2. **「避けたかった現実」と「得られる未来」のギャップを示す**
   （例：50歳で6,000万円を失い、時給850円の草刈り現場から再出発した私が、63歳で資産1.5億円を再構築するまで）
3. **誇大広告・怪しい表現を避ける**
   「誰でも絶対に稼げる」といった表現は、かえって読者の信頼を失います。あなたのリアルな実体験と**事実どおりの数字**こそが、最大の武器です。

> ⚠️ **実績の数字は「期間」とセットで書く**
> 「時給850円から1.5億円」のように途中を省くと、短期間で達成したように読めてしまいます。年齢や年数を必ず添えてください。

> ⚠️ **キーワードの詰め込みは避ける**
> 「副業 稼ぐ AI Kindle 成功 50代」のように検索用の言葉をタイトルに並べることは、KDPのガイドラインで禁止されています。キーワードは登録画面のキーワード欄に入れます（第6章）。

## 3. 紹介文の構成

Amazonの販売ページやBrainの冒頭に載せる「紹介文」は、次の流れで書きます。

```
① 共感（フック）　　：読者が今感じている不安や絶望を代弁する
② 自己紹介（信頼）　：なぜ、あなたがその問題を解決できるのか
③ ベネフィット　　　：この本で分かること・読後にどう変わるか（箇条書き3〜5個）
④ メッセージ　　　　：「もう遅いなんてことはない」という想い
```

### Amazon用とBrain用の違い

| | Amazon（Kindle） | Brain |
|---|---|---|
| 価格を書く | **書かない**（価格は変わるため） | 書いてよい |
| URL・LINE ID・連絡先 | **書かない**（特典の案内は巻末に。第7章） | 規約の範囲で |
| 締めくくり | ④メッセージで終える | ④のあとに価格と案内 |

> 詳しいルールは、KDP・Brainそれぞれの最新ガイドラインで確認してください。

> 💡 第4章のAI設定文のあとに「第3章の企画シートとこの構成で、紹介文の下書きを3パターン作ってください。誇張表現は使わず、私が渡していない数字は入れないでください」と頼むと、たたき台がすぐにできます。

## 4. 表紙を作る

### 表紙で大事なのは「小さくても読める」こと
Amazonの検索結果では、表紙は**切手くらいの大きさ**で表示されます。
細かいデザインより、**タイトルが小さくても読めること**を優先してください。

| 方法 | 費用 | 向いている人 |
|---|---|---|
| Canva（無料のデザインツール）で自作 | 無料〜 | 自分で手を動かしたい人 |
| KDPの「表紙作成ツール」 | 無料 | とにかく早く出したい人 |
| ココナラ等でデザイナーに依頼 | 数千円〜 | 見た目にこだわりたい人 |

### 表紙のチェック
- [ ] スマホで縮小表示しても、タイトルが読める
- [ ] 文字は2〜3色まで、フォントは2種類まで
- [ ] 背景と文字の色がはっきり分かれている
- [ ] 他人の写真・イラストを無断で使っていない（素材の利用規約を確認）
- [ ] サイズはKDPの推奨に合わせた（例：縦長 1,600×2,560ピクセル。**最新の推奨値は公式ヘルプで確認**）

## 5. 価格設定の考え方

### Kindle電子書籍の場合
- 目安は **480円〜980円** 程度。最初の1冊は第1章の導線どおり「入口」なので、**多くの人に読んでもらうこと**を優先します。
- Kindle Unlimited（読み放題）の読者に読んでもらうために、KDPセレクトに登録する方法もあります（登録期間中は他ストアで販売できない等の条件あり）。
- 最初の認知を広げるために、期間限定のキャンペーン価格から始めるのも一つの方法です。

> ⚠️ KDPでは、価格帯によって受け取れるロイヤリティの割合（35％／70％）が変わります。設定できる最低価格や70％の条件は変更されることがあるため、**必ずKDPの公式ヘルプで最新情報を確認**してください。

### Brain教材の場合
- 実務マニュアルや実践ノウハウであれば、**9,800円〜19,800円** 程度が目安です。
- 「この手順どおりにやれば、自力で形にできる」という価値に対して価格を設定します。

## 第5章のまとめ

- 表紙とタイトルは、最初の3秒で「誰の・どんな悩みを解決するか」を伝える命綱。
- 実績の数字は、事実どおりに期間・年齢とセットで書く。
- 紹介文は「共感 → 信頼 → ベネフィット → メッセージ」。Amazonには価格・連絡先を書かない。
- 表紙は「小さくても読める」が最優先。価格は「入口」として考える。

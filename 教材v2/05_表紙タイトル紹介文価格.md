# 第5章 表紙・タイトル・紹介文・価格

## 1. 中身が良くても「見つけてもらえなければ」読まれない

Amazonで読者があなたの本を手に取るかどうかは、ほんの数秒で決まります。
そのとき見ているのは、次の4つだけです。

```
① 表紙（サムネイル）→ ② タイトル → ③ 紹介文 → ④ 価格
```

この章では、この4つを「読者に選ばれる形」に整えます。
作るのは**成果物⑧：タイトル・紹介文の下書き**です。表紙と価格は、決め方の手順を確認します。

## 2. タイトルを決める

### タイトルは「タイトル＋サブタイトル」の2段で考える

- **タイトル**：一目で「自分のための本だ」と分かる短い言葉（15〜25字）
- **サブタイトル**：誰に・何が得られるかを補足（20〜40字）

### 型（第3章の仮タイトルを磨く）

| 型 | 例 |
|---|---|
| 体験＋変化 | 50歳で6,000万円を失った私が、もう一度立ち上がれた理由 |
| 読者への約束 | 50代からの人生再起動 ― 経験を武器に変える成功思考 |
| 問いかけ | なぜ、どん底の人ほどやり直せるのか |

### 3つのチェック
- [ ] 読者（年齢・状況）が想像できる
- [ ] 読後に得られるものが分かる
- [ ] 事実と違う・大げさな数字や言葉が入っていない

> ⚠️ **キーワードの詰め込みは避ける**
> 「副業 稼ぐ AI Kindle 成功 50代」のように、検索用の言葉をタイトルに並べるのはKDPのガイドラインで禁止されています。キーワードは登録画面の「キーワード欄」に入れます（第6章）。

## 3. 紹介文を書く

紹介文は、Amazonの商品ページに表示される「本の説明」です。
次の5つの順番で書くと、読者が最後まで読みやすくなります。

```
① 共感：読者の悩みを言い当てる（2〜3行）
② 著者：なぜ私がこの本を書いたのか（2〜3行）
③ 中身：この本で分かること（箇条書き3〜5個）
④ 対象：こんな人に読んでほしい（箇条書き3個）
⑤ 一言：読者へのメッセージ（1〜2行）
```

> 💡 **紹介文に書かないこと**
> - 「必ず稼げる」「誰でも成功」などの断定・誇張
> - URL、公式LINEのID、メールアドレスなどの連絡先（読者特典の案内は**本の巻末**に書きます。第7章）
> - 事実と違う実績・肩書き
> 詳しいルールはKDPの公式ヘルプで確認してください。

## 4. 表紙を作る

### 表紙で大事なのは「小さくても読める」こと
Amazonの検索結果では、表紙は**切手くらいの大きさ**で表示されます。
細かいデザインより、**タイトルが小さくても読めること**を優先してください。

### 3つの作り方

| 方法 | 費用 | 向いている人 |
|---|---|---|
| Canva（無料のデザインツール）で自作 | 無料〜 | 自分で手を動かしたい人 |
| KDPの「表紙作成ツール」 | 無料 | とにかく早く出したい人 |
| ココナラ等でデザイナーに依頼 | 数千円〜 | 見た目にこだわりたい人 |

### 表紙のチェック
- [ ] スマホで縮小表示しても、タイトルが読める
- [ ] 文字は2〜3色まで、フォントは2種類まで
- [ ] 背景と文字の色がはっきり分かれている
- [ ] 他人の写真・イラストを無断で使っていない（素材の利用規約を確認）
- [ ] サイズはKDPの推奨に合わせた（例：縦長 1,600×2,560ピクセル。**最新の推奨値は公式ヘルプで確認**）

## 5. 価格を決める

### 価格の考え方
最初の1冊の目的は、第1章で決めたとおり**「入口」**です。
売上よりも、**多くの人に読んでもらい、巻末から公式LINEに来てもらうこと**を優先します。

| 価格帯の目安 | 考え方 |
|---|---|
| 低め（数百円） | 手に取ってもらいやすい。入口として最適 |
| 中くらい（〜1,000円台） | 内容の厚みに自信があるとき |

> ⚠️ **ロイヤリティ（印税率）について**
> KDPでは、価格帯によって受け取れるロイヤリティの割合（35％／70％）が変わります。
> 対象となる価格の範囲や条件は変更されることがあるため、**必ず登録時にKDPの公式ヘルプで最新情報を確認**してください。

### Kindle Unlimited（読み放題）について
KDPセレクトに登録すると、読み放題の対象になり、読まれたページ数に応じて収益が入ります。
入口として多くの人に読んでもらいたい場合は、検討する価値があります（登録期間中は、他の電子書籍ストアで同じ本を販売できない等の条件があります。公式ヘルプで確認してください）。

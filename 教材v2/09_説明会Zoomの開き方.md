# 第9章 説明会（Zoom）の開き方

## 1. 説明会は「売る場所」ではなく「地図を渡す場所」

第1章の導線図の**第3段「体験・相談」**が、この説明会です。

```
第2段：公式LINE ＋ 7日間のステップ配信
   ↓ 希望する人だけ
第3段：Zoom説明会 ← この章
   ↓ 希望する人だけ
第4段：本命の商品・サービス
```

LINEのステップ配信を経て説明会に来てくれた人は、あなたのストーリーに共感し、「変わりたい」と願っている人です。
ここでやってはいけないのが、「買ってください」と頭を下げる押し売りです。

説明会の目的は、参加者と一緒にワークシートを埋め、**「今の自分に何が足りず、次に何をすべきか」という地図をはっきりさせて帰ってもらうこと**です。
その結果として、「一人では不安だから伴走してほしい」と**本人が自分で決める**のが理想の流れです。
参加者の多くは、本命の商品を申し込みません。それで構いません。
**申し込まなかった人も「来てよかった」と思える会**にすることが、長い目で見て信頼と評判につながります。

この章で作るのは、**成果物⑫：説明会の台本ひな形（スライド構成つき）**です。

> 第4段（本命の商品）がまだ無い人は、この章は「無料の勉強会・交流会の開き方」として読んでください。台本の「案内」の部分を省けば、そのまま使えます。

## 2. 説明会の前に決めておくこと

| 項目 | 決めること | 例 |
|---|---|---|
| 日時 | 曜日・時間帯 | 平日20時〜／土曜10時〜 |
| 時間 | 全体の長さ | 60分（質疑込み） |
| 定員 | 1回の人数 | 実際に対応できる人数 |
| 申込方法 | 何で受け付けるか | Googleフォーム／Peatix／LINEで「説明会」と返信 |
| 当日の特典 | 参加者に渡すもの | ワークシート（第7章の特典の発展版） |
| 案内の有無 | 最後に有料商品を案内するか | する場合は**事前に告知**する |

> ⚠️ **定員・期限は事実どおりに**
> 「先着◯名」「今日だけ」などは、**実際にそうである場合だけ**使ってください。

## 3. Zoomの準備

### 準備の流れ（目安30分）
1. Zoomのアカウントを作る（無料プランから始められます）
2. 「ミーティングをスケジュール」で日時を設定し、招待リンクを発行する
3. 申込者に、招待リンクを前日と当日（1時間前）に送る
4. 前日までに、家族や友人と**テスト接続**をする

> ⚠️ **無料プランの時間制限**
> Zoomの無料プランには、ミーティング時間の上限があります（執筆時点では40分程度）。60分の説明会を開く場合は、有料プランを検討するか、40分に収まる構成にしてください。最新の条件はZoom公式サイトで確認してください。

### 当日の環境チェック
- [ ] 顔が明るく映る（窓や照明を正面に）
- [ ] 背景が散らかっていない（バーチャル背景でも可）
- [ ] マイクの音が聞き取れる（イヤホンマイク推奨）
- [ ] スライドを「画面共有」できることを確認した
- [ ] 通知（LINE・メールなど）をオフにした
- [ ] 録画する場合は、**参加者に事前に伝えて了承を得る**

## 4. 説明会の流れ（60分）

```
① オープニング　　　　  5分 … あいさつ・今日のゴール・流れ（案内があることも伝える）
② 自己紹介　　　　　　  5分 … どん底から今まで（短く）
③ ワーク　　　　　　　 20分 … 当日の特典シートを一緒に埋める ★メイン
④ 全体像　　　　　　　 10分 … 次の一歩の選択肢（自力でやる道も含めて）
⑤ 案内（希望者向け）　 10分 … 本命の商品の説明
⑥ 質疑応答・クロージング 10分
```

> 💡 **いちばん時間をかけるのは③ワーク**です。
> 参加者が「自分のこと」として手を動かす時間が、説明会の価値になります。説明や案内が長くなりすぎないようにしてください。

> 40分に収める場合の目安：①3分／②3分／③15分／④7分／⑤7分／⑥5分
>
> 90分で行う場合の目安：①5分／②15分（ヒストリーを厚めに）／③30分／④15分／⑤15分／⑥10分
> 講義（ヒストリーや全体像）が長くなっても、**ワークがいちばん長い時間**になるようにしてください。

## 5. 誠実な案内のための7つのルール

説明会で有料の商品を案内する場合は、次のルールを守ってください。

1. **案内があることを、申込時と冒頭で伝える**（「最後に講座のご案内をします」）
2. **収入や結果を約束しない**（「必ず稼げる」「誰でもできる」は使わない）
3. **実績の数字は、本・LP・LINEと同じ表記**にする
4. **「申し込まなくても大丈夫」と、はっきり言う**
5. **その場で決めさせない**（「今日中に決めないと」と急かさない。持ち帰って検討してもらう）
6. **価格・期間・内容・返金条件を、文書で示す**（申込ページ・特定商取引法の表記）
7. **断った人にも、同じように丁寧に接する**

> ⚠️ **法律について**
> Zoomなどで個別に高額な商品を勧める場合、状況によっては特定商取引法の規制（書面の交付、クーリング・オフなど）の対象になる可能性があります。
> 本命の商品を販売する前に、**消費生活センターや弁護士などの専門家に確認**してください。返金に関する表記も、その確認に合わせて整えてください。

## 6. 見本：ハセジュンの説明会台本

私（ハセジュン）が実際に使っている台本の要点です。
**これは見本です。** 実績や体験は私のものなので、次の「7. ワーク」で**あなた自身の言葉に書き換えて**ください。

**オープニング（S1〜S3）**
```
本日はご参加いただき、ありがとうございます。ハセジュンです。

画面の向こうのあなたは、今の生活に満足していますか？
「このままで大丈夫だろうか」という不安を、抱えていませんか？

今日のゴールは、お配りした「反撃ロードマップ決定シート」を一緒に埋めて、
次に何をすればいいかを、はっきりさせて帰っていただくことです。

最後の15分で、私の3ヶ月講座のご案内もさせていただきます。
ただ、申し込まなくても、今日のシートだけで十分に前へ進めます。
安心して、最後までお付き合いください。
```

**ヒストリー（S4〜S5）**
```
私は23歳で成功哲学に出会い、45歳で資産1億円を築きました。
しかし50歳のとき、事業に失敗して6,000万円を失い、
時給850円の草刈り現場で働くことになりました。
若い人たちからの冷たい視線の中で、「私の人生はこれで終わるのか」と絶望しました。

それでも腐らず、かつての成功哲学と、求人誌で気づいた市場のニーズを掛け合わせ、
1年で事業を安定させることができました。
そこから積み重ね、63歳で資産1億5,000万円まで立て直しました。
```

**成功の法則とAI（ワークの前置き）**
```
人生を変えるのに、才能も年齢も関係ありません。
大切なのは「成功は技術である」と知ること、
そして目標を紙に書き、小さな成功を積み重ねて「勝ちグセ」をつけることです。

さらに私たち中高年には、AIという「補助輪」があります。
自分の経験をAIに伝えれば、文章や仕組みを形にするスピードが大きく上がります。

では、ここからシートを一緒に埋めていきましょう。
```

**全体像（S11〜S12）**
```
やるべきことは、シンプルです。
① 自分の人生を棚卸しする
② それをAIを使って、KindleやSNSで発信する
③ 公式LINEを窓口にして、あなたの経験を必要としている人に届ける

今日のシートを持って進む道は、2つあります。
A：自分で進める。本・特典・LINEの内容だけで、十分に進められます。
B：期限と伴走があったほうが進む方は、私の講座で一緒に進めます。
```

**講座のご案内（S13〜S16）**
```
ここからは、Bに興味がある方へのご案内です。

【3ヶ月集中・人生反撃実践講座】
・〔講座の内容：LPと同じ内容を記載〕
・価格：30万円（税込）／分割払い：〔可否・条件〕
・返金条件：〔申込ページ・特定商取引法の表記と同じ内容〕
・結果には個人差があり、成果を保証するものではありません

向いているのは、期限と伴走があると頑張れる方です。
すぐに結果だけが欲しい方には、向いていません。

申込は〔申込方法〕から、〔期限〕までです。
ご家族とも相談のうえ、ゆっくり決めてください。

どちらの道を選んでも、今日書いた「明日の一歩」を、明日やること。
それが、人生後半戦の反撃の始まりです。
```

> ⚠️ **見本で避けている表現**
> - 「本来50万円以上の価値が、今回30万円」など、**実際の販売実績がない元値との比較**（二重価格表示として景品表示法上の問題になるおそれ）
> - 「今日が分岐点です」「今日だけ」など、**その場での決断を迫る言葉**
> - 「この仕組みを作るだけで、収入・時間の自由が手に入る」など、**結果を約束する言葉**
> - 「一人では必ず元に戻る」など、**本・特典だけで進む人を否定する言葉**

## 7. 説明会の台本を作る（ワーク）

### 📝【成果物⑫】説明会の台本ひな形（スライド構成つき）

左がスライド、右が話す内容です。〔　〕を自分の言葉で埋めてください。
台本は**一字一句読む必要はありません**。要点だけ見ながら、自分の言葉で話してください。

---

#### ① オープニング（5分）

| スライド | 話す内容 |
|---|---|
| **S1：タイトル**<br>〔説明会の名前〕<br>〔日付〕〔名前〕 | 「こんばんは、〔名前〕です。今日はお忙しい中、ご参加ありがとうございます。」 |
| **S2：今日のゴール**<br>「次の一歩が、はっきりする」 | 「今日のゴールは、皆さんが帰るときに〔例：次に何をすればいいかが、紙1枚ではっきりしている〕ことです。」 |
| **S3：今日の流れ**<br>①自己紹介 ②ワーク ③全体像 ④ご案内 ⑤質疑 | 「流れはこの通りです。最後に〔講座名〕のご案内を10分ほどさせていただきます。**申し込まなくても、今日のワークだけで十分持ち帰れる内容にしています**ので、安心して参加してください。」 |

#### ② 自己紹介（5分）

| スライド | 話す内容 |
|---|---|
| **S4：私のどん底**<br>〔年齢〕〔出来事〕 | 「〔例：私は50歳のとき、事業に失敗して6,000万円を失いました。〕」<br>（第8章の1日目と同じ話を、短く） |
| **S5：そこからの歩み**<br>年表（3〜4行） | 「〔例：時給850円の仕事から再出発し、1年で事業を安定させ、63歳で資産1億5,000万円まで立て直しました。〕」<br>「特別な才能があったわけではありません。〔例：やり方を変えただけです。〕」 |

> 💡 自己紹介は**5分以内**。長い自慢話は、参加者の心が離れます。

#### ③ ワーク（20分）★メイン

| スライド | 話す内容 |
|---|---|
| **S6：ワークの説明**<br>シートの見本 | 「では、お配りした〔シート名〕を開いてください。今から一緒に埋めていきます。」 |
| **S7：問い1**<br>〔例：今の現在地は？〕 | 「まず1つ目。〔問い〕を3分で書いてください。」（3分待つ）<br>「書けた方、チャットで一言教えてください。」 |
| **S8：問い2**<br>〔例：本当はどうなりたい？〕 | 「2つ目。〔問い〕を書いてください。」（3分）<br>（何人かの書き込みを読み上げて、短くコメント） |
| **S9：問い3**<br>〔例：その間にある壁は？〕 | 「3つ目。〔問い〕です。」（3分）<br>「多くの方が〔よくある壁〕と書かれますね。」 |
| **S10：問い4**<br>〔例：明日できる一歩は？〕 | 「最後に、明日できる一歩を1つ書いてください。」（3分）<br>「これが今日いちばん大事な1行です。」 |

> 💡 チャットへの書き込みは**強制しない**でください。「書ける方だけ」と伝えます。

#### ④ 全体像（10分）

| スライド | 話す内容 |
|---|---|

| **S16：申込方法**<br>URL・期限 | 「ご興味のある方は、〔申込方法〕から。〔期限：例：◯日まで〕に、ご家族とも相談のうえ、ゆっくり決めてください。」 |

### 説明会のあとにやること
- [ ] 参加者全員に、お礼とスライド・シートをLINEで送る（申込の有無に関係なく）
- [ ] 質問への回答で、その場で答えられなかったものを送る
- [ ] 「よかった点・改善点」を3つずつメモする
- [ ] 申し込みの有無を、しつこく追いかけない（案内は1回まで）

### 仕上げのチェック
- [ ] 冒頭で「最後に案内がある」「申し込まなくても大丈夫」と伝えている
- [ ] ワークの時間が全体の3分の1以上ある
- [ ] 実績の数字が、本・LP・LINEと同じ表記
- [ ] 収入や結果を約束する言葉がない
- [ ] 価格・返金条件・「成果には個人差がある」を明示している
- [ ] その場で決めさせる言い方（今日だけ、今すぐ）がない
- [ ] 本命の商品の販売方法について、専門家に確認した（または確認する予定がある）

## 第9章のまとめ

- 説明会は「売る場」ではなく、参加者が**次の一歩を整理する場**。
- いちばん時間をかけるのはワーク。申し込まなかった人も「来てよかった」と思える会に。
- 案内があることは事前に伝え、収入を約束せず、その場で決めさせない。
- 高額な商品を販売する前に、法律面を専門家に確認する。

**クリア条件：成果物⑫の台本が完成し、家族や友人を相手にリハーサルを1回できたら、第9章はクリアです。**

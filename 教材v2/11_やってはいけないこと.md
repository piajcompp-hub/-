# 第11章 やってはいけないこと

## 1. 「知らなかった」では済まされないビジネスの罠

これから自分の経験を発信し、KindleやBrain、さらには講座へとビジネスを広げていく中で、**絶対に越えてはいけない「一線」**があります。
悪気はなくても、一歩間違えれば法律違反になったり、積み上げてきた信用が一瞬で崩れたりすることがあります。

ここでは、私（ハセジュン）の40年の経験と教訓から、**「これだけはやってはいけない6つのこと」**をお伝えします。

> ⚠️ 本章は、法律の一般的な注意点をまとめたものです。法令は改正されることがあり、個別のケースの判断はできません。有料の商品・サービスを販売するときは、**消費者庁の公式情報を確認し、必要に応じて弁護士・消費生活センターなどの専門家に相談**してください。

## 2. やってはいけない6つのこと

### ① 誇大表現・過度な煽り文句・作った実績

**NG例**
- 「誰でもクリックするだけで毎月100万円確実に稼げる」「絶対に損しない裏技」
- 実際より大きい金額や、短い期間で書いた実績
- 実在しない「お客様の声」や、効果が出た人だけを選んで「みんなこうなる」と見せる表示

**理由**
一時的に人は集まるかもしれませんが、中身が伴わなければクレームや返金トラブルにつながり、何よりあなたの信用が深く傷つきます。
実績は**事実どおりに、期間・年齢とセットで**語り、「結果には個人差がある」ことを誠実に伝えましょう。

### ② 他人の文章や画像の無断転用（著作権侵害）

**NG例**
- 他人のブログ記事をそのままコピーして、自分の本やBrainに載せる
- ネット上の画像を、勝手に表紙やスライドに使う

**理由**
著作権の侵害になり、KDPやBrainのアカウントが停止される原因にもなります。
引用する場合は、**必要な範囲にとどめ、引用部分を明確に分け、出所を明記**してください。基本は、自分の言葉と体験で書くことです。画像は、利用規約を確認した素材か、自分で撮影・作成したものを使います。

### ③ 特定商取引法・景品表示法の無視

**NG例**
- 有料の講座やコンサルを、運営者の氏名・連絡先などを記載せずに販売する
- 実際に販売したことのない「通常価格◯◯円」と並べて、今の価格を安く見せる（二重価格表示）
- 報酬をもらって紹介しているのに、「広告」「PR」と書かずに、個人の感想のように投稿する（ステルスマーケティング）

**理由**
- **特定商取引法**：インターネットで有料の商品やサービスを販売する場合、販売者の氏名・住所・電話番号・価格・返品条件などの表示が原則として義務付けられています（一定の条件で、住所・電話番号を「請求があれば遅滞なく開示する」とする方法もあります）。
- **景品表示法**：実際より著しく優良・有利に見せる表示は禁止されています。2023年10月からは、広告であることを隠した表示（ステマ）も規制の対象です。Brainのアフィリエイトで紹介してもらう場合や、自分が紹介する場合は、**「広告」「PR」などの表示**を入れましょう。

### ④ AI文章の「丸投げ・コピペ放置」

**NG例**
- AIが出力した文章を読まず、事実確認もせずに、そのまま出版・投稿する

**理由**
AIは時々、存在しない法律、間違った数字、話していないエピソードを、もっともらしく出力します（ハルシネーション）。読者からの信頼を失うだけでなく、①の誇大表現や事実と違う実績につながることもあります。
必ず自分の目でチェックし、第4章の「5つのチェック」を通して、あなたの「体温」を吹き込みましょう。KDPでは、AIの使用について**正直に申告**することも忘れずに（第6章）。

### ⑤ プライバシーや機密情報の暴露

**NG例**
- 過去の仕事や現場で関わった人の実名、未公開の社内情報、許可を取っていない第三者のエピソードを、特定できる形で書く
- 説明会を、参加者の同意なく録画・公開する

**理由**
思わぬトラブルや、法的責任を問われる原因になります。
他人のエピソードを使う場合は、**仮名にする、状況を変えるなど、個人が特定されないよう**配慮してください。公式LINEの友だち情報やアンケートの回答も、大切な個人情報として扱います。

### ⑥ 決断を急がせる売り方

**NG例**
- 「今日が人生の分岐点」「今決めないと二度とチャンスはない」と、その場で申し込ませる
- 実際には締め切らないのに「先着◯名」「残り◯席」と書く
- 断った人に、何度も連絡して申し込みを迫る

**理由**
こうした売り方は、後悔や「だまされた」という気持ちを生み、返金トラブルや悪い評判につながります。
さらに、Zoomや電話などで個別に高額な商品を勧める場合、状況によっては特定商取引法の規制（書面の交付、クーリング・オフなど）の対象になる可能性があります。
**価格・条件を文書で示し、持ち帰って考えてもらう**のが、長く信頼される売り方です（第9章）。

## 3. 公開前チェックリスト（全章共通の最終関門）

新しいKindle・Brain・LP・LINE配信・SNS投稿・説明会資料を世に出す**直前に**、必ず確認してください。

### 📝【公開前チェックリスト】

**事実と表現**
- [ ] **事実に嘘はないか**：実績や数字（資産額・損失額・期間・年齢）に、誇張や偽りはないか
- [ ] **表記はそろっているか**：実績の書き方が、本・LP・LINE・SNSで同じか
- [ ] **結果を約束していないか**：「必ず」「絶対」「誰でも」「◯万円稼げる」などがないか。「結果には個人差がある」と書いたか
- [ ] **お客様の声は本物か**：本人の許可を得た、実際の声だけを使っているか

**権利と法律**
- [ ] **著作権はクリアか**：他人の文章・画像の無断使用がないか。引用は出所を明記したか
- [ ] **特商法の表記はあるか**：有料販売のページに、販売者・連絡先・価格・返品条件などが正しく書かれているか
- [ ] **価格表示は正しいか**：実績のない「通常価格」との比較をしていないか
- [ ] **広告の表示はあるか**：紹介料・報酬をもらう投稿に「広告」「PR」と書いたか

**AIと個人情報**
- [ ] **AIの確認は済んだか**：事実確認と、自分の言葉への書き換えを行ったか
- [ ] **個人情報は守られているか**：第三者が特定される内容がないか。録画は同意を得たか

**案内と導線**
- [ ] **有料の案内を明示したか**：説明会などで有料商品の案内がある場合、事前に伝えているか
- [ ] **急がせていないか**：実際と違う「先着」「今だけ」を書いていないか
- [ ] **リンクは正しいか**：あなたの公式LINEのURL・ID、特典リンク、申込URLが正しく動くか（自分のスマホで確認）

## 第11章のまとめ

- 誇大表現・作った実績・著作権侵害は、信用の失墜やアカウント停止を招く。絶対に避ける。
- 有料販売では、特定商取引法・景品表示法（二重価格・ステマ規制を含む）のルールを守る。
- AIはあくまで補助輪。最終的な情報の正確さと責任は、**あなた自身**にある。
- 決断を急がせず、条件を文書で示す。それが長く信頼される一番の近道。
- 何かを公開する前には、必ず「公開前チェックリスト」を通す。

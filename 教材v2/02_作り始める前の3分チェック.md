# 第2章 作り始める前の3分チェック

## 1. なぜチェックが必要なのか？

途中で止まる原因の多くは、才能ではなく**準備不足**です。
「アカウントが作れない」「時間が取れない」「何を書くか決まらない」。どれも、作り始める前に3分確認すれば防げます。

この章では、**今の自分がスタートできる状態かどうか**を確認し、足りないものを先に用意します。

## 2. 3つの確認ポイント

### ① 環境（道具がそろっているか）
パソコン、メールアドレス、各サービスのアカウントなど。
後の章で「登録できずに止まる」のを防ぎます。

### ② 時間（いつやるか決まっているか）
「時間ができたらやる」は、ほぼ実行されません。
**曜日と時間帯**を先に決めます。

### ③ 中身（何を書くか見えているか）
第1章の導線図と、書きたいテーマの方向性。
完璧でなくて構いません。**一言で言えれば十分**です。

## 3. ワーク

### 📝【成果物②】スタート前チェック表

当てはまるものに ✓ を入れてください。

**① 環境**
- [ ] 文章を書けるパソコンがある（スマホだけでも可。ただし登録作業はPC推奨）
- [ ] 本書専用に使えるメールアドレスがある
- [ ] Amazonアカウントがある（KDP登録で使用）
- [ ] 振込先の銀行口座が手元で確認できる（KDPの収益受取で使用）
- [ ] AIチャットツールにログインできる
- [ ] 公式LINEアカウントを作る準備ができている（第7章で使用）

**② 時間**
- [ ] 作業する曜日を決めた：＿＿＿曜日
- [ ] 作業する時間帯を決めた：＿＿時〜＿＿時
- [ ] 1回あたりの作業時間を決めた：＿＿分（目安30〜60分）
- [ ] 第1章〜第10章を終える目標日を決めた：＿＿月＿＿日

**③ 中身**
- [ ] 成果物①（導線図）の「入口」と「特典」が埋まっている
- [ ] 書きたいテーマを一言で言える：「＿＿＿＿＿＿＿＿」
- [ ] そのテーマを読んでほしい人を一言で言える：「＿＿＿＿＿＿＿＿」

### 判定

| ✓の数 | 判定 | 次にやること |
|---|---|---|
| すべて ✓ | スタートOK | 第3章へ進む |
| 1〜3個 空欄 | ほぼOK | 空欄を今日中に埋めてから第3章へ |
| 4個以上 空欄 | 準備期間 | 今週は準備に使い、来週から第3章へ |

> 空欄が多くても問題ありません。**どこが足りないかが分かったこと自体が前進**です。

## 第2章のまとめ

- 止まる原因の多くは準備不足。先に3分で確認する。
- 環境・時間・中身の3つをそろえる。
- 時間は「できたら」ではなく、**曜日と時間帯**で決める。

**クリア条件：成果物②の判定が「スタートOK」または「ほぼOK」になったら、第2章はクリアです。**

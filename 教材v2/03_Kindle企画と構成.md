# 第3章 Kindle企画と構成

## 1. 企画がブレると、文章は書けなくなる

「さあ、Kindleを書くぞ」となったとき、多くの人がパソコンの白い画面を前にしてフリーズします。
理由は、**「誰に向けて、どんな悩みを解決し、読後にどうなってほしいのか」という企画の軸（地図）がない**からです。

本書の読者である中高年・ビジネス層が求めているのは、綺麗な文学作品ではありません。
**「あなたの実体験に基づいた、泥臭くても真似できる手順」**です。

この章で作るのは、次の3つです。

| 成果物 | 内容 | 目安時間 |
|---|---|---|
| ③ 企画シート | 誰に・何を・どう変えるか | 20分 |
| ④ 章立て | 本の骨組み（目次） | 30分 |
| ⑤ 書く計画（日割り） | いつ・どこを書くか | 10分 |

合計約1時間。ここまで終われば、あとは「埋めるだけ」の状態になります。

## 2. 企画の4要素を決める

1. **ターゲット（誰のどんな悩みを解決するか？）**
   例：50代でビジネスに行き詰まり、これからの人生に希望を持てずにいる元・経営者や会社員
2. **ゴール（読後にどういう状態になってほしいか？）**
   例：「自分にもまだやり直せる武器がある」と気づき、明日からの行動を1つ決められる状態
3. **あなたの独自性（なぜ、あなたがそれを語るのか？）**
   例：50歳で6,000万円を失い、時給850円の仕事から再起した実体験
4. **本のタイトル（仮）**
   読者が一目で「自分のための本だ」と分かるタイトル。正式なものは第5章で作ります。

> 💡 **ゴールは小さくていい**
> 「人生が変わる」ではなく、「明日の行動が1つ決まる」くらいの、**読者が本当に受け取れる大きさ**にしてください。大きすぎる約束は、レビューで「期待外れ」と書かれる原因になります。

> 💡 **独自性に書く数字は、事実どおりに**
> 金額・期間などの実績は、読者が誤解しない書き方にしてください。誇張は信頼を一瞬で失います。

| 項目 | 記入 |
|---|---|
| 書籍タイトル（仮） | |

## 3. 人生年表から「章立て」を作る

企画が決まったら、目次（章立て）を作ります。
人生年表（または第2章の「10分テーマ決めワーク」のメモ）から、今回のテーマに直結するエピソードやノウハウを選び、次の構成に当てはめます。

```
序章　：共感（私のどん底と、そこからの気づき）
第1章 ：原因（なぜ、人は失敗し、動けなくなるのか）
第2章 ：発見（人生の転換点、光を見つけた瞬間）
第3章 ：手法（具体的にどうやって立て直したか）
第4章 ：習慣（それを維持するための成功思考とAI等の活用）
終章　：決意（読者へのエールと、次のステップ・特典の案内）
```

### 各章の中身の型
どの章も、次の3点セットで書くと迷いません。

1. **体験**：そのとき何が起きたか
2. **気づき**：そこから何を学んだか
3. **読者へ**：あなたならどうするか（問いかけ・小さな行動）

### 📝【成果物④】章立て

| 章 | 章タイトル | 書く体験（1行） | 伝える気づき（1行） | 目標字数 |
|---|---|---|---|---|
| 序章 | | | | 2,000 |
| 第1章 | | | | 3,000 |
| 第2章 | | | | 3,000 |
| 第3章 | | | | 4,000 |
| 第4章 | | | | 3,000 |
| 終章 | | | | 2,000 |
| **合計** | | | | **17,000** |

> 💡 「書く体験」の欄が埋まらない章は、無理に作らず削ってください。**5章でも立派な1冊**です。

## 4. 書く計画を「1日目標」に落とし込む

目次ができたら、いつまでに書き上げるかの日割りスケジュールを作ります。
「時間ができたら書こう」では、なかなか書けません。見出し単位に小さく分けて、毎日の目標にします。

### 1日の量は「逆算」で決める

```
総文字数 ÷ 書く日数 ＝ 1日の目標文字数
```

| 総文字数 | 期間 | 1日の目標 | 1日の作業時間の目安 |
|---|---|---|---|
| 15,000字 | 14日 | 約1,100字 | 30〜45分 |
| 15,000字 | 30日 | 500字 | 15〜20分 |
| 20,000字 | 40日 | 500字 | 15〜20分 |

> 第2章で決めた「作業時間」と「初稿の期限」に合うものを選んでください。
> AIで下書きを作る場合（第4章）、負担はさらに軽くなります。ただし、**体験の部分は必ず自分の言葉で**書いてください。

### 予備日を入れる
予定通りに進まない日は必ずあります。**3〜4日に1日は「予備日」**にしておくと、遅れても計画が崩れません。

### 📝【成果物⑤】書く計画（日割りスケジュール）

- 総文字数の目安：＿＿＿＿字
- 1日の目標文字数：＿＿＿＿字
- 書き始める日：＿＿月＿＿日
- 完成予定日：＿＿月＿＿日（予備日込み）

| 日 | 日付 | 書く範囲（見出し単位） | 目標字数 | 完了 |
|---|---|---|---|---|
| 1 | ／ | | | □ |
| 2 | ／ | | | □ |

## 第3章のまとめ

- 企画（誰に・何を・どう届けるか）が先で、執筆は後。
- 目次は全5〜6章のシンプルな構造。各章は「体験 → 気づき → 読者へ」。
- 1日の目標は「総文字数 ÷ 日数」で逆算し、予備日を入れる。

**クリア条件：成果物③④⑤がそろい、書き始める日が決まったら、第3章はクリアです。**

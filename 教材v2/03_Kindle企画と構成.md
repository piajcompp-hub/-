# 第3章 Kindle企画と構成

## 1. いきなり書き始めない

テーマが決まると、すぐに本文を書きたくなります。
でも、設計図なしで家を建てないのと同じで、**企画と章立てなしに書き始めると、途中で迷子になりやすくなります。**

この章で作るのは、次の3つです。

| 成果物 | 内容 | 目安時間 |
|---|---|---|
| ③ 企画シート | 誰に・何を・どう変えるか | 20分 |
| ④ 章立て | 本の骨組み（目次） | 30分 |
| ⑤ 書く計画（日割り） | いつ・どこを書くか | 10分 |

合計1時間。ここまで終われば、あとは「埋めるだけ」の状態になります。

## 2. 企画シートを作る

### 企画で決めるのは4つだけ

1. **読者**：誰が読むのか（第2章で決めたテーマの「誰に」）
2. **悩み**：その人が今、困っていること（本人の言葉で）
3. **約束**：読み終えたとき、何ができる・分かるようになるか
4. **自分だから書ける理由**：あなたの経験のどこが、その悩みの解決になるのか

> 💡 **「約束」は小さくていい**
> 「人生が変わる」ではなく、「最初の一歩が分かる」「同じ失敗を避けられる」くらいの、**読者が本当に受け取れる大きさ**にしてください。大きすぎる約束は、レビューで「期待外れ」と書かれる原因になります。

### タイトルの仮決め
この段階のタイトルは仮で構いません（正式なものは第5章で作ります）。
次の型に当てはめると作りやすくなります。

- 「〔数字・状況〕から〔変化〕した〔方法〕」
  例：「50歳でゼロになった私が、1年で立ち上がった7つの習慣」
- 「〔読者〕のための〔テーマ〕入門」
  例：「定年前の50代のための、経験を本にする入門」

### 📝【成果物③】企画シート

| 項目 | 記入 |
|---|---|
| 仮タイトル | |
| 読者（年齢・状況を具体的に） | |
| 読者の悩み（本人の言葉で） | |
| 読み終えたときの約束 | |
| 自分だから書ける理由 | |
| 本の最後で案内する特典（第1章の導線図②） | |

## 3. 章立てを作る

### 初めての1冊の目安
- **文字数**：1万5千〜3万字（短すぎず、最後まで書き切れる量）
- **構成**：はじめに ＋ 本文5〜7章 ＋ おわりに
- **1章あたり**：3,000〜5,000字

### 章立ての基本の流れ
読者が「自分ごと」として読み進められる、次の順番がおすすめです。

```
はじめに　：なぜこの本を書いたか／誰のための本か
第1章　　：私のどん底（共感）
第2章　　：なぜそうなったのか（原因）
第3章　　：抜け出すきっかけ（転機）
第4章　　：実際にやったこと①
第5章　　：実際にやったこと②
第6章　　：あなたが今日からできること（行動）
おわりに　：読者へのメッセージ／特典の案内
```

### 各章の中身の型
どの章も、次の3点セットで書くと迷いません。

1. **体験**：そのとき何が起きたか
2. **気づき**：そこから何を学んだか
3. **読者へ**：あなたならどうするか（問いかけ・小さな行動）

### 📝【成果物④】章立て

| 章 | 章タイトル | 書く体験（1行） | 伝える気づき（1行） | 目標字数 |
|---|---|---|---|---|
| はじめに | | | | 1,500 |
| 第1章 | | | | |
| 第2章 | | | | |
| 第3章 | | | | |
| 第4章 | | | | |
| 第5章 | | | | |
| 第6章 | | | | |
| おわりに | | | | 1,500 |
| **合計** | | | | |

> 💡 「書く体験」の欄が埋まらない章は、無理に作らず削ってください。**5章でも立派な1冊**です。

## 4. 書く計画（日割り）を作る

### 1日の量を決める
第2章で決めた「作業時間」と「初稿の期限」から逆算します。

```
合計字数 ÷ 書く日数 ＝ 1日に書く字数
例）20,000字 ÷ 14日 ≒ 1,500字／日（30〜45分）
```

> AIで下書きを作る場合（第4章）、1日の負担はさらに軽くなります。
> ただし、**体験の部分は必ず自分の言葉で**書いてください。

### 予備日を入れる
予定通りに進まない日は必ずあります。**3〜4日に1日は「予備日」**にしておくと、遅れても計画が崩れません。

### 📝【成果物⑤】書く計画（14日の例）

| 日 | 日付 | 書く範囲 | 目標字数 | 完了 |
|---|---|---|---|---|

| 3 | ／ | 第1章 後半 | 1,500 | □ |
| 4 | ／ | **予備日** | − | □ |
| 5 | ／ | 第2章 | 2,500 | □ |

※ご自身の章立て・日数に合わせて書き換えてください。

## 第3章のまとめ

- 本文を書く前に、企画・章立て・計画の3つを1時間で作る。
- 約束は「読者が本当に受け取れる大きさ」にする。
- 各章は「体験 → 気づき → 読者へ」の3点セット。
- 計画には必ず予備日を入れる。

**クリア条件：成果物③④⑤の3つがそろい、計画の1日目の日付が決まったら、第3章はクリアです。**

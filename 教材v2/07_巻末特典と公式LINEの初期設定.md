# 第7章 巻末特典と公式LINEの初期設定

## 1. 本を「読み終わったら終わり」にしない

Kindleを読んだ読者と、あなたの関係は、ふつうは**本を閉じた瞬間に終わります**。
Amazonは、誰があなたの本を買ったかを教えてくれません。

そこで、第1章の導線図の**第2段「特典 → 公式LINE」**をつなぎます。

```
本の巻末で特典を案内
   ↓
読者が公式LINEに友だち追加
   ↓
あいさつメッセージで特典をプレゼント
   ↓
（第8章）7日間のステップ配信で、信頼を深める
```

この章で作るのは、**成果物⑩：公式LINEの初期設定完了＋あいさつ文**です。
あわせて、巻末に入れる特典と案内文も作ります。

> ⚠️ **画面について**
> LINE公式アカウントの画面や料金プランは、ときどき変更されます。本書と表示が違う場合は、**画面の表示とLINEの公式ヘルプを優先**してください。

## 2. 巻末特典を決める

### 特典は「本の続き」になるものを
読者が「もらいたい」と思うのは、**本を読んだ直後に、すぐ使えるもの**です。

| 特典の例 | 作り方 | 手間 |
|---|---|---|
| 本のワークシート（PDF） | 本文のワークを1枚にまとめる | 小 |
| チェックリスト | 本の要点を10項目に | 小 |
| AIプロンプト集 | 第4章の依頼文を読者向けに | 小 |
| 解説動画・音声 | スマホで10分話して録る | 中 |
| 本に入らなかった番外編 | 削ったエピソードを1本 | 中 |

> 💡 **最初は「ワークシート」がおすすめです。**
> 本文のワークをそのまま使えるので、すぐ作れます。第1章の導線図③にある「Zoom説明会で一緒に埋める」ともつながります。

### 特典の渡し方
特典のファイルは、GoogleドライブやDropboxにアップロードし、**リンクを知っている人だけが見られる設定**にして、そのリンクをLINEで送ります。

> ⚠️ 共有設定が「編集可能」になっていないか確認してください。「閲覧のみ」にします。

## 3. 公式LINEを作る

### STEP1：アカウントを作る（15分）
1. 「LINE公式アカウント 開設」で検索し、公式サイトから申し込む
2. 普段使っているLINEアカウント、またはメールアドレスでログイン
3. アカウント名・業種などを入力して作成
4. スマホに「LINE公式アカウント」アプリを入れておくと、外出先でも管理できます

### STEP2：プロフィールを整える（15分）

| 項目 | 入れるもの |
|---|---|
| アカウント名 | 著者名（Kindleと同じ名前） |
| プロフィール画像 | 顔写真、または表紙と同じ雰囲気の画像 |
| ステータスメッセージ | 一言の紹介（例：「50歳からの人生再起動を応援」） |
| 背景画像 | 本の表紙など（任意） |

### STEP3：料金プランを確認する
最初は**無料プラン**で十分です。
ただし、無料プランには**毎月送れるメッセージ数に上限**があります。友だちが増えて上限に近づいたら、有料プランを検討してください。
※上限の数や料金は変更されることがあります。公式サイトで確認してください。

### STEP4：特典を自動で届ける設定

読者が友だち追加したとき、**自動で届くあいさつメッセージ**に特典のリンクを入れます。
これで、あなたが寝ている間も特典が届きます。

さらに、「特典」と送ってきた人に自動で返す**キーワード応答**を設定しておくと、あいさつを見逃した人にも届けられます。

| 設定 | 場所（目安） | 内容 |
|---|---|---|
| あいさつメッセージ | ホーム → あいさつメッセージ | 下の⑩のあいさつ文＋特典リンク |
| 応答メッセージ | ホーム → 応答メッセージ | キーワード「特典」→ 特典リンク |

### STEP5：友だち追加用のURLとQRコードを取得
「友だち追加ガイド」などのメニューから、**友だち追加用のURL**と**QRコード**を取得します。
これを巻末の案内に入れます。

> 💡 Kindleはスマホで読む人が多いので、**QRコードよりURLのほうがタップしやすい**です。両方入れておくのが安心です。

## 4. 巻末の案内文を作る

本の最後（著者プロフィールの前後）に、次のような案内を入れます。
第6章の原稿ファイルに戻って、追加してください。

```
━━━━━━━━━━━━━━━━━━━━
【読者限定特典のご案内】

最後までお読みいただき、ありがとうございました。
本書のワークを1枚にまとめた「〔特典名〕」を、
公式LINEで無料でお届けしています。

▼友だち追加はこちら
〔友だち追加URL〕
（QRコード）

友だち追加後、自動でお届けします。
届かない場合は「特典」と送ってください。
━━━━━━━━━━━━━━━━━━━━
```

> ⚠️ **案内は控えめに**
> KDPでは、本の中身が「外部への誘導が中心」になっているものは問題になることがあります。案内は**巻末に1か所、本の価値を補う形**にとどめてください。
> また、Amazonの「内容紹介」欄にはURLやLINE IDを書かないでください（第5章）。

## 5. あいさつ文を作る（ワーク）

あいさつメッセージは、読者があなたと**最初に交わす言葉**です。
次の5つの順番で書くと、温かく、売り込み感のない文章になります。

```
① お礼：本を読んでくれたこと、友だち追加してくれたことへの感謝
② 自己紹介：ひとこと（長くしない）
③ 特典：約束のプレゼントとリンク
④ これから：明日から何が届くか（第8章のステップ配信の予告）
⑤ 安心：いつでもブロックしてOK、売り込みはしない
```

### 📝【成果物⑩】公式LINE初期設定 ＋ あいさつ文

**初期設定チェック**
- [ ] 公式LINEアカウントを作成した
- [ ] アカウント名・プロフィール画像・ステータスメッセージを設定した
- [ ] 料金プラン（無料プランの送信上限）を確認した
- [ ] 特典ファイルを作り、「閲覧のみ」のリンクを用意した
- [ ] あいさつメッセージを設定した
- [ ] キーワード「特典」の応答メッセージを設定した
- [ ] 友だち追加URL・QRコードを取得した
- [ ] 巻末に特典の案内文を入れた
- [ ] **自分のスマホで友だち追加し、特典が届くことを確認した**

**あいさつ文（テンプレート）**

```
〔ニックネーム〕さん、はじめまして。
『〔本のタイトル〕』の著者、〔著者名〕です。

本を最後まで読んでくださり、
そして友だち追加まで、本当にありがとうございます。

お約束の読者特典はこちらです。
▼〔特典名〕
〔特典のリンク〕

明日から7日間、本には書ききれなかった
〔テーマ：例「どん底から立ち上がるまでの話」〕を、
1日1通お届けします。

売り込みのメッセージは送りません。
合わないと感じたら、いつでもブロックしてくださいね。

これから、よろしくお願いします。
```

> 💡 「〔ニックネーム〕」の部分は、LINEの機能で**友だちの名前を自動で差し込む**ことができます（設定画面で「友だちの表示名」を挿入）。

## 第7章のまとめ

- Amazonは読者を教えてくれない。巻末特典で公式LINEにつなぐ。
- 特典は「本の続き」。最初はワークシートで十分。
- あいさつメッセージ＋キーワード応答で、特典を自動で届ける。
- 巻末の案内は1か所、控えめに。Amazonの内容紹介にはURLを書かない。
- 最後に必ず、自分で友だち追加して届くか確認する。

**クリア条件：成果物⑩の初期設定チェックがすべて埋まり、自分のスマホで特典が届いたら、第7章はクリアです。**

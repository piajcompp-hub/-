# 第7章 巻末特典と公式LINEの初期設定

## 1. なぜ「巻末特典」と「公式LINE」が必要なのか？

Kindle出版やBrainの販売は、作って終わりではありません。
Amazonは、誰があなたの本を買ったかを教えてくれません。読者との関係は、ふつうは**本を閉じた瞬間に終わります**。

いちばん大切なのは、**あなたの本を読んで共感してくれた読者と、その後も直接つながれる導線**を作ることです。

```
本の巻末で「読者限定特典」を案内
   ↓
読者が公式LINEに友だち追加
   ↓
あいさつメッセージで特典をプレゼント
   ↓
（第8章）7日間のステップ配信で、信頼を深める
```

これにより、あなたの本が「ただの読み物」から、**読者とつながり続ける入口**に変わります。
この章で作るのは、**成果物⑩：公式LINEの初期設定完了＋あいさつ文**です。

> ⚠️ LINE公式アカウントの画面や料金プランは、ときどき変更されます。本書と表示が違う場合は、**画面の表示とLINE公式ヘルプを優先**してください。

## 2. 読者が登録したくなる「巻末特典」の作り方

特典は、新しく難しいものを作る必要はありません。
本文で使ったワークシートやAIへの依頼文を、PDFやGoogleスプレッドシートの形に整えるだけで、立派な特典になります。

### 見本：ハセジュンの「5大特典」

- 特典①：成功思考チェックリスト（PDF）
- 特典②：人生逆転・集中ワークブック（書き込み用シート）
- 特典③：AI発信プロンプト集（テキストファイル）
- 特典④：成功哲学10箇条（カード画像またはPDF）
- 特典⑤：AI×経験「人生反撃ロードマップ」（図解シート）

> 💡 **最初は1つで十分です。**
> 5つそろえようとすると、ここで手が止まります。まずは**本文のワークを1枚にまとめたワークシート**だけで始め、あとから増やしてください。

### 特典の渡し方
1. ファイルをGoogleドライブなどに保存する
2. 共有設定を**「リンクを知っている全員」＋「閲覧者」**にする
3. 共有リンク（URL）をコピーしておく

> ⚠️ 共有設定が「編集者」になっていると、読者がファイルを書き換えられてしまいます。必ず「閲覧者」にしてください。

## 3. 公式LINEの初期設定

### STEP1：アカウントを作る（15分）
「LINE Official Account Manager」（official-account.line.biz）から、LINE公式アカウントを作成します。
スマホに「LINE公式アカウント」アプリを入れておくと、外出先でも管理できます。

### STEP2：プロフィールを整える（15分）

| 項目 | 入れるもの |
|---|---|
| アカウント名 | 名前とテーマがひと目で分かる名称（例：「ハセジュン【人生反撃】」） |
| プロフィール画像 | 顔写真、または信頼感のある写真（スーツ姿など） |
| ステータスメッセージ | 一言の紹介（例：「50歳からの人生再起動を応援」） |

### STEP3：料金プランを確認する
最初は**無料プラン**で十分です。
ただし、無料プランには**毎月送れるメッセージ数に上限**があります。友だちが増えて上限に近づいたら、有料プランを検討してください（上限や料金は公式サイトで確認）。

### STEP4：特典を自動で届ける設定

| 設定 | 内容 |
|---|---|
| あいさつメッセージ | 友だち追加した瞬間に自動で届く。特典のリンクを入れる（下の成果物⑩） |
| 応答メッセージ（キーワード） | 「特典」と送られたら、特典のリンクを自動で返す（あいさつを見逃した人用） |

### STEP5：友だち追加URL・QRコードを取得
管理画面の「友だち追加ガイド」などから、**友だち追加用のURL**と**QRコード**を取得します。
Kindleはスマホで読む人が多いので、**URLのほうがタップしやすい**です。両方入れておくと安心です。

## 4. 巻末の案内文を入れる

第6章の原稿ファイルに戻り、本の最後（著者プロフィールの前後）に追加します。

```
━━━━━━━━━━━━━━━━━━━━
【読者限定特典のご案内】

最後までお読みいただき、ありがとうございました。
本書のワークを1枚にまとめた「〔特典名〕」を、
公式LINEで無料でお届けしています。

▼友だち追加はこちら
〔友だち追加URL〕
（QRコード）

友だち追加後、自動でお届けします。
届かない場合は「特典」と送ってください。
━━━━━━━━━━━━━━━━━━━━
```

> ⚠️ **案内は控えめに**
> KDPでは、本の中身が「外部への誘導が中心」になっているものは問題になることがあります。案内は**巻末に1か所、本の価値を補う形**にとどめてください。Amazonの「内容紹介」欄にはURLやLINE IDを書きません（第5章）。

## 5. 登録直後に送る「あいさつメッセージ」

あいさつメッセージは、読者があなたと**最初に交わす言葉**です。
次の5つを入れると、温かく、行動につながる文章になります。

```
① お礼：友だち追加してくれたことへの感謝
② 特典：約束のプレゼントとリンク
③ 使い方：特典をどの順番で使えばいいか
④ これから：明日から何が届くか（第8章の予告）
⑤ 最初の一歩：今日やってほしい小さな行動（返信など）
```

### 見本：ハセジュンのあいさつメッセージ

```
ご登録ありがとうございます！
ハセジュンです。

まず、お約束の「5大特典」を受け取ってください。
これは単なる資料ではなく、あなたの人生後半戦を
組み立て直すための【5つの道具】です。

🎁【特典1】成功思考チェックリスト
🎁【特典2】人生逆転・集中ワークブック
🎁【特典3】AI発信プロンプト集
🎁【特典4】成功哲学10箇条
🎁【特典5】AI×経験「人生反撃ロードマップ」

👇【5大特典のダウンロードはこちら】
〔特典のダウンロードURL〕

💡【ハセジュン流・おすすめの活用手順】
1. まず「特典4」を読む。（私の40年のエッセンスをつかむ）
2. 次に「特典1」で自分を採点する。（現在地と伸びしろを確認する）
3. そして「特典2」を埋める。（これが本命。あなたの経験を資産に変える）
4. 最後に「特典3・5」で仕組みを理解する。

明日から、あなたの考え方を「成功思考」に切り替えるための
メッセージを毎朝お届けします。

まずは今日、特典1のチェックリストを開いて、
「YES」の数を、このLINEに数字だけで返信してください。
あなたの現在地に合わせたヒントをお送りします。

私と一緒に、人生後半戦の反撃を始めましょう！
```

### 「数字で返信」を自動にする
「返信してくれたら、ヒントを送る」と約束したら、必ず返す必要があります。
友だちが増えると手作業では追いつかないので、**応答メッセージ（キーワード）で、数字ごとに自動で返す**設定をしておきます。

| 届く数字（例：10問中） | 自動で返すヒント |
|---|---|
| 0〜3 | 「まずは特典4を1日1つだけ読んでみてください」 |
| 4〜7 | 「特典2のワークブックの1ページ目から始めましょう」 |
| 8〜10 | 「特典5のロードマップで、次の一手を決めましょう」 |

> 💡 数字ひとつずつ（「0」「1」…「10」）をキーワードとして登録します。

## 6. あなたの公式LINEを完成させる（ワーク）

### 📝【成果物⑩】公式LINE初期設定 ＋ あいさつ文

**初期設定チェック**
- [ ] 公式LINEアカウントを作成した
- [ ] アカウント名・プロフィール画像・ステータスメッセージを設定した
- [ ] 料金プラン（無料プランの送信上限）を確認した
- [ ] 特典ファイルを作り、「閲覧者」のリンクを用意した
- [ ] あいさつメッセージを設定した
- [ ] キーワード「特典」の応答メッセージを設定した
- [ ] （返信をお願いする場合）数字ごとの応答メッセージを設定した
- [ ] 友だち追加URL・QRコードを取得した
- [ ] 巻末に特典の案内文を入れた
- [ ] **自分のスマホで友だち追加し、特典が届くことを確認した**

**あいさつ文（あなた用テンプレート）**

見本を参考に、自分の言葉で書き換えてください。特典が1つなら、③の使い方は1行で構いません。

```
ご登録ありがとうございます！
『〔本のタイトル〕』の著者、〔著者名〕です。

お約束の読者特典はこちらです。
🎁〔特典名〕
👇
〔特典のリンク〕

💡【使い方】
〔例：まず1ページ目のチェック欄に◯をつけてみてください。〕

明日から7日間、本には書ききれなかった
〔テーマ：例「どん底から立ち上がるまでの話」〕を、
1日1通お届けします。

まずは今日、〔小さな行動：例「チェックの数を数字で返信」〕してください。

これから、よろしくお願いします！
```

## 第7章のまとめ

- Amazonは読者を教えてくれない。巻末特典で公式LINEにつなぐ。
- 特典は手持ちのワークシートをPDF化するだけでいい。**最初は1つで十分**。
- あいさつメッセージで特典を渡し、最初の小さな行動（返信など）を促す。
- 返信をお願いしたら、キーワード応答で必ず返る仕組みにする。
- 巻末の案内は1か所、控えめに。最後に自分で受け取りを確認する。

**クリア条件：成果物⑩の初期設定チェックがすべて埋まり、自分のスマホで特典が届いたら、第7章はクリアです。**

# 第8章 ステップ配信の組み立て

## 1. 登録されたあと、放置していませんか？

公式LINEに読者が登録してくれたあと、毎日手動でメッセージを送る必要はありません。
LINE公式アカウントの**「ステップ配信」機能**を使えば、友だち追加した日から数えて「1日目、2日目……」と、決めておいたメッセージが自動で届きます。
（Lステップ等の有料の外部ツールもありますが、最初は公式LINEの標準機能で十分です。）

ここで大切なのは、**最初の数日間は商品を売らないこと**です。
読者はまだあなたを信用していません。いきなり高額な案内をすると、すぐにブロックされてしまいます。

第1章の導線図でいえば、ここは**第2段「教育・信頼」**です。

```
第1段：本（入口）
   ↓
第2段：公式LINE ＋ 7日間のステップ配信 ← この章
   ↓
第3段：説明会（希望する人だけ）
```

この7日間の目的は、**売ることではありません**。
本では伝えきれなかった体験と考え方を届け、読者に**小さな行動を7回積み重ねてもらう**ことです。
その結果として、「この人の話をもっと聞きたい」と思った人だけが、次の段へ進みます。

この章で作るのは、**成果物⑪：7日分の配信文**です。

> ⚠️ LINE公式アカウントの画面や機能名は変更されることがあります。本書と表示が違う場合は、**画面の表示とLINE公式ヘルプを優先**してください。

## 2. 7日間の設計図

7日間は、**本の章立て（第3章）と同じ流れ**で組み立てると、迷わず書けます。

| 日 | テーマ | 目的 | 読者にお願いする小さな行動 |
|---|---|---|---|
| 1日目 | 共感：私のどん底 | 「この人も同じだった」と感じてもらう | 自分のいちばん苦しかった時期を1行書く |
| 2日目 | 原因：なぜ動けなくなるのか | 自分を責めるのをやめてもらう | 自分の「思い込み」を1つ書き出す |
| 3日目 | 発見：転機の瞬間 | 変われるきっかけはある、と知ってもらう | 自分の過去の小さな成功を1つ思い出す |
| 4日目 | 手法：最初にやったこと | 具体的な一歩を知ってもらう | 今日5分でできる行動を1つ決める |
| 5日目 | 習慣：続けるコツ | 続ける仕組みを知ってもらう | 明日の朝やることを1つ書く |
| 6日目 | ワーク：特典を使う | 特典で自分の現在地を整理してもらう | 特典のワークシートを埋める |
| 7日目 | 決意：これからの一歩 | 次の選択肢を示す（希望者のみ） | 7日間でできたことを振り返る |

> 💡 **毎日1つ、「小さな行動」を必ず入れる**
> 読むだけのメッセージは、すぐ流されます。行動をお願いし、「できたら〇〇と返信してください」と添えると、読者との距離が縮まります。
> 返信をお願いする場合は、第7章と同じように**キーワード応答で自動で返事が届く**ようにしておきます。

## 3. 1通の型

1通は**300〜500字**、スマホの画面で2〜3回スクロールする程度が目安です。
次の4つの順番で書きます。

```
① つかみ：今日のテーマを一言で（1〜2行）
② 体験：自分のエピソード（5〜10行）
③ 気づき：そこから学んだこと（2〜3行）
④ 行動：今日やってほしい小さなこと（1〜2行）
```

> 💡 **本の文章を使い回してOKです。**
> 本の各章から、いちばん伝えたいエピソードを1つ選び、短くするだけで配信文になります。第4章のAI設定文のあとに「この本文を、LINE用に400字に短くしてください。最後に読者への小さな行動を1つ入れてください」と頼むと、たたき台がすぐにできます。

## 4. 7日目の「案内」の書き方

7日目には、第3段（説明会など）の案内を入れます。
ここで大事なのは、**売り込みにしない**ことです。

- 7日間読んでくれたことへの感謝を、まず伝える
- 案内は**希望する人だけ**に向けて、短く
- 「参加しなくても、ここまでの内容で十分前に進めます」と添える
- 有料の講座につながる場合は、**そのことを正直に書く**

> 第3段がまだ無い人は、7日目は「振り返り＋これからも配信を続けます」で終えて構いません（第1章の「最初は2段で十分」）。

## 5. ステップ配信を設定する

### 設定の流れ（目安30分）
1. LINE公式アカウントの管理画面で「ステップ配信」を開く
2. 新しいステップ配信を作成し、開始条件を「友だち追加」にする
3. 1日目〜7日目のメッセージを、それぞれ「友だち追加から◯日後」に設定する
4. 配信時刻を決める（例：毎朝7時。読者の生活に合わせて）
5. 保存して、配信を開始する

> ⚠️ **送信数の上限に注意**
> ステップ配信のメッセージも、料金プランの送信数に含まれます。
> 「友だちの数 × 7通」が、毎月の上限を超えないか確認してください（第7章 STEP3）。

### 必ずテストする
- [ ] 自分のスマホ（または家族のスマホ）で友だち追加し、1日目が届くか確認した
- [ ] 文字化け・リンク切れがない
- [ ] 7日目まで、毎日届くことを確認した（最初の1週間は実際に受け取って確かめる）

## 6. 見本：ハセジュンの7日間

ここでは、私（ハセジュン）が実際に使っている7日間を公開します。
**これは見本です。** 実績や体験は私のものなので、そのままコピーせず、次の「7. ワーク」で**あなた自身の体験に書き換えて**ください。

### 全体設計
- **1〜3日目（信頼編）**：成功は技術であること／未来を書き出す／AIという補助輪
- **4〜5日目（体験編）**：過去の苦労が価値に変わる理由／成功哲学10箇条
- **6〜7日目（案内編）**：説明会の予告と、希望者への案内

> 💡 LINEには件名の欄がありません。下の「件名」は、**1行目の見出し**として入れます（通知に最初に表示される部分です）。

**【1日目】思考：成功は「技術」である**
```
👉「その努力、9割ムダかもしれません」

ハセジュンです。

「人間は、自分が思い描いた通りの人生を生きる」

これは魔法ではなく、「技術」です。
23歳で成功哲学に出会い、3ヶ月で600万円。45歳で資産1億円。
50歳でゼロになっても、63歳で1億5,000万円まで立て直せたのは、
この技術を手放さなかったからです。

成功思考チェックリスト（特典①）の「YES」の数を、
このLINEに数字で教えてください。
あなたの現在地に合わせたヒントが届きます。
```

**【2日目】目標：未来を「予約」する**
```
👉「本当は、どんな人生を送りたかったですか？」

ハセジュンです。
特典②のワークブックを書くときは、現実に縛られないでください。

「書く」ことは、未来を「予約」することです。

誰にも指図されず、平日の昼間に温泉でゆっくり過ごす。
大切な人に、値段を気にせずプレゼントを贈る。
培ってきた経験で、誰かに「ありがとう」と言われる。

特典②の3ページ目「理想の1日」を、ワクワクしながら埋めてください。
そこが、あなたの新しい人生のスタートラインです。
```

**【3日目】解決：AIという補助輪**
```
👉「変わる人は、ここから始めています」

ハセジュンです。

私たち中高年には、若い頃ほど時間がありません。
だからこそ、AIという「補助輪」が役に立ちます。

60代の私にもできました。
難しいことはAIに手伝ってもらい、あなたは「自分の経験」を語るだけでいい。

今日、特典③のプロンプト集から1つだけ試してみてください。
思ったより簡単なことに、きっと驚くはずです。
```

**【4日目】実証：経験は「原石」である**
```
👉「あなたの経験は、磨けば光る原石です」

ハセジュンです。

かつて私が時給850円の現場で味わった悔しさ。
それさえも今では、「救われました」と言っていただける本や講座の材料になりました。

あなたの30年、40年のキャリアも、磨けば光る原石です。
特典②で掘り起こした経験を、特典⑤のロードマップに沿って形にしていく。
それが、経験を「誰かの役に立つ価値」に変える第一歩です。

あなたが「無駄だった」と思っている苦労を、1つ教えてください。
```

**【5日目】決意：何歳からでも変えられる**
```
👉「多くの人が、ここでつまずきます」

ハセジュンです。

才能も年齢も、関係ありません。
必要なのは「まだ終わっていない」という、たった一つの確信です。

私の人生の指針「成功哲学10箇条（特典④）」の第1条。
「人生は何歳からでも変えられる」

明日1日の小さな目標を、このLINEで宣言してください。
その積み重ねが、大きな逆転を生みます。
```

**【6日目】予告：反撃の全体像**
```
👉「明日、全体像をお話しします」

ハセジュンです。

この数日間で、あなたの中に「もう一度やってみよう」という火が灯っていたら嬉しいです。

明日は、5つの特典をどうつなげ、
あなたの経験をどう形にしていくのか、
その「全体像」と、これからの選択肢をお話しします。
```

**【7日目】案内：反撃計画の始まり**
```
👉「7日間、ありがとうございました」

ハセジュンです。
7日間、私のメッセージを読んでくださり、ありがとうございました。

最後なので、少しだけ厳しいことを言わせてください。
知識は「知っている」だけでは、何も変わりません。
「行動」して初めて、現実は動き出します。

この7日間で「自分もまだ輝けるはずだ」という小さな火が灯ったなら、
その火を消さないでほしいのです。

そのために、無料のZoom説明会を開いています。

📣【反撃計画・Zoom説明会（無料）】
・5大特典をどうつなげ、あなたの経験をどう形にするかをお話しします
・参加者には「反撃ロードマップ決定シート」を差し上げ、当日一緒に埋めます
・説明会の最後に、3ヶ月の伴走講座（有料）のご案内をします

講座に申し込まなくても、
シートを埋めるだけで「次に何をすればいいか」は整理できます。

一人ひとりと丁寧に対話したいので、各回10名までとさせてください。

👇説明会の詳細・お申し込みはこちら（希望する方のみ）
〔説明会の申込URL〕

ハセジュン
```

> ⚠️ **見本で気をつけていること**
> - 「30万稼げる」「必ず変わる」など、**収入や結果を約束する言葉は使わない**
> - 説明会で**有料講座の案内があることを、事前に明記する**
> - 定員・期限などは、**実際の条件どおりに**書く（実際に締め切らない「先着◯名」は書かない）
> - 実績の数字・年齢は、本・紹介文・LPと**同じ表記**にそろえる

### 説明会を「ワーク完走者」だけに案内したい場合
7日目のメッセージは、通常は全員に届きます。
6日目以降に「完了」と返信した人だけに案内したい場合は、LINE公式アカウントの**タグ（属性）機能や、絞り込み配信**を使います。設定方法は公式ヘルプで確認してください。
設定しない場合は、「ワーク完走者限定」とは書かず、「希望する方のみ」と書きます。

- [ ] 7通すべてに「小さな行動」が入っている
- [ ] 1通あたり300〜500字程度
- [ ] 実績の数字・年齢が、本や紹介文と同じ表記になっている

- [ ] 返信をお願いした言葉（「書いた」「完了」など）に、自動応答を設定した

## 第8章のまとめ

- ステップ配信は、友だち追加から自動で順番に届く仕組み。目的は売ることではなく、信頼と小さな行動。
- 7日間は本の章立てと同じ流れ。1通は「つかみ・体験・気づき・行動」の4つ。
- 7日目の案内は希望者のみ。有料につながる場合は正直に書く。
- 送信数の上限と、自分のスマホでのテストを忘れない。

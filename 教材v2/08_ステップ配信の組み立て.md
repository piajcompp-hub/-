# 第8章 ステップ配信の組み立て

## 1. ステップ配信とは

ステップ配信とは、友だち追加した日を起点に、**決めておいたメッセージを順番に自動で届ける**仕組みです。
一度作れば、いつ誰が友だち追加しても、その人に「1日目、2日目……」と同じ流れで届きます。

第1章の導線図でいえば、ここは**第2段「教育・信頼」**です。

```
第1段：本（入口）
   ↓
第2段：公式LINE ＋ 7日間のステップ配信 ← この章
   ↓
第3段：説明会（希望する人だけ）
```

この7日間の目的は、**売ることではありません**。
本では伝えきれなかった体験と考え方を届け、読者に**小さな行動を7回積み重ねてもらう**ことです。
その結果として、「この人の話をもっと聞きたい」と思った人だけが、次の段へ進みます。

この章で作るのは、**成果物⑪：7日分の配信文**です。

> ⚠️ LINE公式アカウントの画面や機能名は変更されることがあります。本書と表示が違う場合は、**画面の表示とLINE公式ヘルプを優先**してください。

## 2. 7日間の設計図

7日間は、**本の章立て（第3章）と同じ流れ**で組み立てると、迷わず書けます。

| 日 | テーマ | 目的 | 読者にお願いする小さな行動 |
|---|---|---|---|
| 1日目 | 共感：私のどん底 | 「この人も同じだった」と感じてもらう | 自分のいちばん苦しかった時期を1行書く |
| 2日目 | 原因：なぜ動けなくなるのか | 自分を責めるのをやめてもらう | 自分の「思い込み」を1つ書き出す |
| 3日目 | 発見：転機の瞬間 | 変われるきっかけはある、と知ってもらう | 自分の過去の小さな成功を1つ思い出す |
| 4日目 | 手法：最初にやったこと | 具体的な一歩を知ってもらう | 今日5分でできる行動を1つ決める |
| 5日目 | 習慣：続けるコツ | 続ける仕組みを知ってもらう | 明日の朝やることを1つ書く |
| 6日目 | ワーク：特典を使う | 特典で自分の現在地を整理してもらう | 特典のワークシートを埋める |
| 7日目 | 決意：これからの一歩 | 次の選択肢を示す（希望者のみ） | 7日間でできたことを振り返る |

> 💡 **毎日1つ、「小さな行動」を必ず入れる**
> 読むだけのメッセージは、すぐ流されます。行動をお願いし、「できたら〇〇と返信してください」と添えると、読者との距離が縮まります。
> 返信をお願いする場合は、第7章と同じように**キーワード応答で自動で返事が届く**ようにしておきます。

## 3. 1通の型

1通は**300〜500字**、スマホの画面で2〜3回スクロールする程度が目安です。
次の4つの順番で書きます。

```
① つかみ：今日のテーマを一言で（1〜2行）
② 体験：自分のエピソード（5〜10行）
③ 気づき：そこから学んだこと（2〜3行）
④ 行動：今日やってほしい小さなこと（1〜2行）
```

> 💡 **本の文章を使い回してOKです。**
> 本の各章から、いちばん伝えたいエピソードを1つ選び、短くするだけで配信文になります。第4章のAI設定文のあとに「この本文を、LINE用に400字に短くしてください。最後に読者への小さな行動を1つ入れてください」と頼むと、たたき台がすぐにできます。

## 4. 7日目の「案内」の書き方

7日目には、第3段（説明会など）の案内を入れます。
ここで大事なのは、**売り込みにしない**ことです。

- 7日間読んでくれたことへの感謝を、まず伝える
- 案内は**希望する人だけ**に向けて、短く
- 「参加しなくても、ここまでの内容で十分前に進めます」と添える
- 有料の講座につながる場合は、**そのことを正直に書く**

> 第3段がまだ無い人は、7日目は「振り返り＋これからも配信を続けます」で終えて構いません（第1章の「最初は2段で十分」）。

## 5. ステップ配信を設定する

### 設定の流れ（目安30分）
1. LINE公式アカウントの管理画面で「ステップ配信」を開く
2. 新しいステップ配信を作成し、開始条件を「友だち追加」にする
3. 1日目〜7日目のメッセージを、それぞれ「友だち追加から◯日後」に設定する
4. 配信時刻を決める（例：毎朝7時。読者の生活に合わせて）
5. 保存して、配信を開始する

> ⚠️ **送信数の上限に注意**
> ステップ配信のメッセージも、料金プランの送信数に含まれます。
> 「友だちの数 × 7通」が、毎月の上限を超えないか確認してください（第7章 STEP3）。

### 必ずテストする
- [ ] 自分のスマホ（または家族のスマホ）で友だち追加し、1日目が届くか確認した
- [ ] 文字化け・リンク切れがない
- [ ] 7日目まで、毎日届くことを確認した（最初の1週間は実際に受け取って確かめる）

## 6. 7日分の配信文を作る（ワーク）

### 📝【成果物⑪】7日分の配信文

各日、〔　〕を埋めてください。見本は書き方の例です。自分の体験に置き換えてください。

---

**1日目：共感「私のどん底」**

見本：
```
おはようございます。ハセジュンです。

今日は、私のいちばん苦しかった時期の話をさせてください。

50歳のとき、私は事業に失敗し、6,000万円を失いました。
それまで積み上げてきたものが、一瞬でゼロになりました。
次の仕事は、時給850円の現場でした。
夜、ひとりで「もう終わりだ」と何度も思いました。

でも今振り返ると、あのどん底が、
人生を組み立て直すスタート地点でした。

【今日の一歩】
あなたの「いちばん苦しかった時期」を、1行だけノートに書いてみてください。
書けたら「書いた」と返信してくださいね。
```

あなたの配信文：
```
①つかみ：〔　〕
②体験：〔　〕
③気づき：〔　〕
④行動：〔　〕
```

---

**2日目：原因「なぜ動けなくなるのか」**
```
①つかみ：〔例：動けないのは、あなたの能力のせいではありません。〕
②体験：〔当時の自分の判断・思い込み〕
③気づき：〔今だから分かる原因〕
④行動：〔例：あなたの「どうせ無理」を1つ書き出してみてください。〕
```

---

**3日目：発見「転機の瞬間」**
```
①つかみ：〔例：人生が変わり始めたのは、ある小さな出来事からでした。〕
②体験：〔転機になった出来事・出会い・言葉〕
③気づき：〔考え方がどう変わったか〕
④行動：〔例：過去の「小さくてもうまくいったこと」を1つ思い出してください。〕
```

---

**4日目：手法「最初にやったこと」**
```
①つかみ：〔例：私が最初にやったのは、とても小さなことでした。〕
②体験：〔具体的な最初の一歩・期間・頻度〕
③気づき：〔なぜそれが効いたのか〕
④行動：〔例：今日、5分でできることを1つ決めて、やってみてください。〕
```

---

**5日目：習慣「続けるコツ」**
```
①つかみ：〔例：始めるより、続けるほうが難しい。〕
②体験：〔今も続けている習慣・続かなかった失敗〕
③気づき：〔続けるための工夫〕
④行動：〔例：明日の朝やることを1つ、今夜のうちに書いておいてください。〕
```

---

**6日目：ワーク「特典を使う」**
```
①つかみ：〔例：今日は、特典のワークシートを一緒に使いましょう。〕
②説明：〔ワークシートのどこから、どう埋めるか〕
③気づき：〔埋めると何が分かるか〕
④行動：〔例：ワークシートを埋めたら「完了」と返信してください。〕
※特典のリンクをもう一度入れておく
```

---

**7日目：決意「これからの一歩」**

見本：
```
7日間、最後まで読んでくださり、ありがとうございました。

この1週間で、あなたは
・苦しかった時期を言葉にし
・思い込みに気づき
・小さな一歩を踏み出しました。
それは、確かな前進です。

もし「次に何をすればいいか、一緒に整理したい」と思われたら、
無料のZoom説明会で、ワークシートを一緒に埋める時間を用意しています。
説明会では、私の3ヶ月講座（有料）のご案内もしますが、
参加しなくても、ここまでの内容で十分前に進めます。

▼説明会の詳細はこちら（希望する方のみ）
〔説明会の案内URL〕

これからも、ときどきメッセージをお届けします。
人生後半戦、一緒に組み立て直していきましょう。
```

あなたの配信文：
```
①感謝：〔　〕
②振り返り：〔7日間でできたこと〕
③案内（希望者のみ・任意）：〔　〕
④これから：〔　〕
```

---

### 仕上げのチェック
- [ ] 7通すべてに「小さな行動」が入っている
- [ ] 1通あたり300〜500字程度
- [ ] 実績の数字・年齢が、本や紹介文と同じ表記になっている
- [ ] 「必ず」「絶対」「誰でも」などの誇張表現がない
- [ ] 7日目の案内は希望者向けで、有料講座につながる場合はそう書いてある
- [ ] 返信をお願いした言葉（「書いた」「完了」など）に、自動応答を設定した

## 第8章のまとめ

- ステップ配信は、友だち追加から自動で順番に届く仕組み。目的は売ることではなく、信頼と小さな行動。
- 7日間は本の章立てと同じ流れ。1通は「つかみ・体験・気づき・行動」の4つ。
- 7日目の案内は希望者のみ。有料につながる場合は正直に書く。
- 送信数の上限と、自分のスマホでのテストを忘れない。

**クリア条件：成果物⑪の7通が完成し、ステップ配信を設定して、自分のスマホで1日目が届いたら、第8章はクリアです。**

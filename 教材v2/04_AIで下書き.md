# 第4章 AIで下書き（補助輪として）

## 1. AIは「書き手」ではなく「補助輪」

AIに「本を書いて」と頼むと、それらしい文章はすぐに出てきます。
でも、その文章には**あなたの体験が入っていません**。誰が書いても同じ、読者の心に残らない本になります。

本書でのAIの役割は、自転車の**補助輪**です。

| あなたがやること | AIに任せること |
|---|---|
| 体験を話す・答える | 質問を投げかけて、記憶を引き出す |
| 事実・数字を確認する | 話した内容を見出しごとに整理する |
| 自分の言葉で仕上げる | 読みやすい下書きに整える |
| 最終判断をする | 誤字脱字・言い回しのチェック |

ポイントは、**AIに書かせるのではなく、AIに質問させる**ことです。
AIがインタビュアーになり、あなたが答える。その答えを元に下書きを作る。これなら、中身は100％あなたの体験です。

この章で作るのは、次の2つです。

| 成果物 | 内容 |
|---|---|
| ⑥ AI設定文 | 毎回最初に貼る「AIへの指示書」 |
| ⑦ 章別の質問文セット | 第3章の章立てに沿った、章ごとの依頼文 |

## 2. AIを使う前の4つのルール

1. **数字・年齢・金額は、必ず自分で確認する**
   AIは事実を勝手に作ることがあります。実績の数字は、他の媒体（note・LP等）と同じ表記にそろえてください。
2. **他人の個人情報は入力しない**
   家族・取引先などは、名前を伏せるか仮名にします。
3. **出てきた文章は、そのまま使わない**
   最低でも2〜3割は自分の言葉で書き直します。特に「体験」の部分は自分の言葉で。
4. **KDPの規定を確認する**
   KDPでは、AIで生成した内容について登録時に申告を求められます。最新の規定は公式ヘルプで確認してください（第6章で再度扱います）。

## 3. AI設定文を作る

毎回の作業の最初に貼る「指示書」です。一度作れば、全章で使い回せます。
ChatGPTの「カスタム指示」や、Claudeの「プロジェクト」機能に登録しておくと、毎回貼る手間が省けます。

### 📝【成果物⑥】AI設定文（テンプレート）

〔　〕の部分を、第3章の企画シートから書き写してください。

```
あなたは、実体験をもとにしたビジネス書の編集者兼インタビュアーです。
これから私のKindle本の原稿づくりを手伝ってください。

【本の企画】
・仮タイトル：〔　　　　〕
・読者：〔年齢・状況・悩み〕
・読後のゴール：〔　　　　〕
・私の独自のエピソード：〔　　　　〕

【あなたの役割】
1. 私の体験を引き出すために、質問を1つずつしてください。
   一度に複数の質問をしないでください。
2. 私の答えが抽象的なときは「具体的には？」「そのとき何を感じましたか？」と深掘りしてください。
3. 十分に材料が集まったら、私の言葉をできるだけ残して下書きにしてください。

【守ってほしいこと】
・私が話していない事実・数字・エピソードを作らないでください。
・「必ず稼げる」「誰でも成功する」などの誇張表現は使わないでください。
・文体は「です・ます調」、読者に語りかける口調で、1文を短くしてください。
・中高年の読者が読みやすいよう、専門用語は使わないか、言い換えてください。
```

> 💡 **「事実を作らない」の一文が最も大事です。**
> これがないと、AIはそれらしい成功談を勝手に付け足すことがあります。

## 4. 章別の質問文セットを使う

### 1章ごとの進め方（3ステップ）

```
① 質問を受ける：章別の依頼文を貼り、AIの質問に答える（15〜20分）
② 下書きを作る：「ここまでの答えで下書きにして」と頼む（5分）
③ 自分で仕上げる：読み直し、自分の言葉に書き直す（20〜30分）
```

答えるときは、**上手に話そうとしなくて大丈夫**です。話し言葉のまま、思い出した順に書いてください。スマホの音声入力を使うと、さらに楽になります。

### 📝【成果物⑦】章別の質問文セット

第3章の章立て（序章〜終章）に合わせた依頼文です。AI設定文のあとに、該当する章の文を貼ってください。
〔　〕には、成果物④の章タイトルと書く体験を入れます。

**序章：共感（私のどん底と、そこからの気づき）**
```
序章「〔章タイトル〕」の材料を集めます。
テーマは「私のいちばん苦しかった時期」です。〔書く体験〕
読者が「これは自分のことだ」と感じられるよう、
当時の状況・感情・周囲の反応を、質問で1つずつ引き出してください。
```

**第1章：原因（なぜ、人は失敗し、動けなくなるのか）**
```
第1章「〔章タイトル〕」の材料を集めます。
テーマは「なぜ私はそうなったのか、その原因」です。〔書く体験〕
当時の判断・思い込み・見えていなかったことを、質問で引き出してください。
最後に、読者が同じ失敗をしないための教訓を一緒に言葉にしてください。
```

**第2章：発見（人生の転換点、光を見つけた瞬間）**
```
第2章「〔章タイトル〕」の材料を集めます。
テーマは「立ち直るきっかけになった出来事・出会い・言葉」です。〔書く体験〕
その瞬間の場面（いつ・どこで・誰と）と、考え方がどう変わったかを、
質問で具体的に引き出してください。
```

**第3章：手法（具体的にどうやって立て直したか）**
```
第3章「〔章タイトル〕」の材料を集めます。
テーマは「実際にやったことの手順」です。〔書く体験〕
読者が真似できるよう、
・何から始めたか
・どのくらいの期間・頻度でやったか
・うまくいかなかったこと、どう修正したか
を、順番に質問してください。最後に手順を3〜5ステップに整理してください。
```

**第4章：習慣（それを維持するための成功思考とAI等の活用）**
```
第4章「〔章タイトル〕」の材料を集めます。
テーマは「立て直した状態を続けるために、今も続けている習慣」です。〔書く体験〕
毎日・毎週やっていること、考え方のクセ、使っている道具（AIなど）を、
質問で引き出してください。読者が今日から1つ始められる形にまとめてください。
```

**終章：決意（読者へのエールと、次のステップ・特典の案内）**
```
終章「〔章タイトル〕」の材料を集めます。
テーマは「この本を読み終えた読者に、いちばん伝えたいこと」です。
私がなぜこの本を書いたのか、読者に何をしてほしいのかを質問で引き出してください。
最後に、読者特典〔特典の内容〕と公式LINEへの案内を、
売り込みにならない自然な文章で2〜3行の下書きにしてください。
```

### 困ったときの追加の依頼文

| 状況 | 依頼文 |
|---|---|
| 答えが浅い気がする | 「今の答えを、もう一段深掘りする質問を3つください」 |
| 下書きが自分らしくない | 「私の答えの言い回しを、できるだけそのまま残して書き直してください」 |
| 長すぎる | 「意味を変えずに、〇〇字に短くしてください」 |
| 読みにくい | 「1文を40字以内にし、中学生でも分かる言葉に直してください」 |
| 事実確認したい | 「この下書きの中で、私が話していない内容があれば指摘してください」 |

## 5. 仕上げのチェック

下書きを自分の原稿にする前に、次を確認してください。

- [ ] 私が話していない事実・数字・エピソードが入っていない
- [ ] 年齢・金額・期間が、他の媒体と同じ表記になっている
- [ ] 誇張表現（必ず・絶対・誰でも 等）が入っていない
- [ ] 体験の部分を、自分の言葉で書き直した
- [ ] 声に出して読んで、自分の話し方として違和感がない

## 第4章のまとめ

- AIは「書き手」ではなく「補助輪」。**AIに質問させ、自分が答える。**
- AI設定文には「事実を作らない」を必ず入れる。
- 1章ごとに「質問に答える → 下書き → 自分で仕上げる」の3ステップ。

**クリア条件：成果物⑥（AI設定文）が完成し、序章1つ分の下書きを⑦の依頼文で作れたら、第4章はクリアです。**

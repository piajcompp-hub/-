# 第4章 AIで下書き（補助輪として）

## 1. AIは「主役」ではなく「補助輪」である

「AIに文章を書かせると、どこか機械的で自分の想いが伝わらない気がする……」
そんな不安を持つ方もいるかもしれませんが、安心してください。

本書のスタンスは、**「AIに丸投げする」ことではありません。**
AIを「補助輪（優秀な編集者・秘書）」として使い、あなたの頭の中にある経験や想いを、速く引き出して形にすることです。

64歳の私でも、AIを相棒にすることで、執筆のスピードは大きく上がりました。
この章では、ITが苦手な方でもそのまま真似できる「AIの初期設定」と「頼み方のコツ」を公開します。

| あなたがやること | AIに任せること |
|---|---|
| 体験を箇条書きで渡す | 箇条書きを読みやすい文章に整える |
| 数字・事実を確認する | 構成案・言い回しの提案 |
| 自分の言葉（体温）を足す | 誤字脱字・長さの調整 |

## 2. AIを使う前の3つの約束

1. **他人の個人情報は入力しない**
   家族・取引先などは、名前を伏せるか仮名にしてください。
2. **数字・年齢・金額は、必ず自分で確認する**
   実績の表記は、note・LP・Kindleなど全ての媒体で同じにそろえます。
3. **KDPの規定を確認する**
   KDPでは、AIで作った内容について登録時に申告を求められます。最新の規定は公式ヘルプで確認してください（第6章で再度扱います）。

## 3. AIを「自分専属の編集者」にする初期設定

まずはAI（ChatGPT、Claude、Geminiなど）に、「これからどんな役割で仕事をしてもらうか」を伝えます。これを**「役割設定」**と言います。
以下の文章（成果物⑥）を、AIとの最初のチャットに貼り付けてください。

> 💡 ChatGPTの「カスタム指示」や、Claudeの「プロジェクト」機能に登録しておくと、毎回貼る手間が省けます。

### 📝【成果物⑥】AI設定文（コピペ用）

〔　〕の部分は、第3章の企画シートから書き写してください。

```
あなたは出版のプロフェッショナルであり、私（シニア起業家・執筆者）の専属編集者です。
私のこれまでの人生経験（どん底からの復活）や成功哲学をベースにした、Kindle書籍の執筆をサポートしてください。

【本の企画】
・仮タイトル：〔　　　　〕
・読者：〔年齢・状況・悩み〕
・読後のゴール：〔　　　　〕

【書き方】
・キレイゴトだけの文章や、AI特有の硬い表現にしないでください。
・私の熱量や生々しい体験が読者にまっすぐ伝わる、人間味のある分かりやすい日本語にしてください。
・「です・ます調」で、1文は短く。専門用語は使わないか、言い換えてください。
・私が渡すメモや箇条書きを元に、下書きや構成案を提案してください。

【必ず守ること】
・私が書いていない事実・数字・エピソードを、絶対に付け足さないでください。
・材料が足りないときは、勝手に補わず「〇〇について教えてください」と私に質問してください。
・「必ず稼げる」「誰でも成功する」などの誇張表現は使わないでください。
```

この設定をしておくことで、AIはあなた専属の編集者として動き始めます。

> 💡 **【必ず守ること】の3行は消さないでください。**
> これがないと、AIは「それらしい成功談」や「キリのいい数字」を勝手に足すことがあります。

## 4. 章ごとに使う「質問文セット」

第3章で作った章立てに沿って、各章の中身をAIと一緒に膨らませていきます。
大事なのは順番です。**先にあなたが具体的なエピソードや感情を箇条書きで渡し、AIはそれを文章に整えるだけ**にします。

### 1章ごとの進め方

```
① 見出しごとに、エピソードを箇条書きにする（10〜15分）
② 下の依頼文に貼り付けて、AIに下書きを作ってもらう（5分）
③ 5つのチェックで、自分の言葉に戻す（20〜30分）
```

1章（2,000〜4,000字）は、**見出し2〜3個に分けて、1回約1,500字ずつ**頼むと質が安定します。

### 📝【成果物⑦】章別の質問文セット

**基本の依頼文（全章共通）**
```
【現在の章】第○章：〔章のタイトル〕
【今回の見出し】〔見出し〕
【この見出しで伝えたいメッセージ】〔例：絶望の底でも、小さな目標を1つクリアすれば、勝ちグセは取り戻せる〕
【私の具体的なエピソード（箇条書き）】
・当時、〇〇な状態だった
・周りからはこう言われて悔しかった
・ここでした決定的な行動は〇〇だった
上記の素材だけを使って、読者が共感し、次のページへ進みたくなる本文（約1,500字）の下書きを作ってください。
素材にない事実は足さないでください。
```

**章ごとの「箇条書きにする内容」のヒント**

| 章 | 箇条書きにする内容 |
|---|---|
| 序章：共感 | いちばん苦しかった時期の状況／そのときの感情／周りの反応／読者に重なる部分 |
| 第1章：原因 | 当時の判断／思い込み／見えていなかったこと／今だから分かる教訓 |
| 第2章：発見 | 転機の出来事・出会い・言葉／いつ・どこで・誰と／考え方がどう変わったか |
| 第3章：手法 | 最初にやったこと／期間と頻度／うまくいかなかったこと／どう修正したか |
| 第4章：習慣 | 今も続けている毎日・毎週の習慣／考え方のクセ／使っている道具（AI等） |
| 終章：決意 | この本を書いた理由／読者にしてほしいこと／特典と公式LINEの案内（売り込みにしない） |

### 手が止まったときは「インタビュー方式」

箇条書きが出てこないときは、AIに質問してもらいます。

```
第○章「〔章のタイトル〕」の材料が思い出せません。
私の体験を引き出す質問を、1つずつしてください。
答えが抽象的なときは「具体的には？」と深掘りしてください。
材料が集まったら、箇条書きにまとめてください。
```

### 困ったときの追加の依頼文

| 状況 | 依頼文 |
|---|---|
| 自分らしくない | 「私の箇条書きの言い回しを、できるだけそのまま残して書き直してください」 |
| 長すぎる | 「意味を変えずに、〇〇字に短くしてください」 |
| 読みにくい | 「1文を40字以内にし、中学生でも分かる言葉に直してください」 |
| 事実確認したい | 「この下書きの中で、私の箇条書きにない内容があれば全て指摘してください」 |

## 5. AIの文章を「自分の言葉」に戻す5つのチェック

AIが書いた文章をそのまま使うのはNGです。次の5点を確認し、あなたの体温を吹き込んでください。

- [ ] **数字・固有名詞**：AIが作った数字や、事実と違う名前が入っていない
- [ ] **付け足し**：自分の箇条書きにないエピソードが入っていない
- [ ] **誇張表現**：「必ず」「絶対」「誰でも」などが入っていない
- [ ] **語り口**：です・ます等のトーンが、自分のキャラクターと合っている
- [ ] **生々しさ**：いちばん苦しかった瞬間の感情や、泥臭いディテールを自分の言葉で1〜2行書き足した

この5つを通すだけで、AIの下書きが「あなただけの血の通った原稿」に変わります。

## 第4章のまとめ

- AIは丸投げの道具ではなく、想いを形にする「補助輪（編集者）」。
- 初期設定（成果物⑥）には「事実を付け足さない」を必ず入れる。
- 自分のエピソードを箇条書きで渡し（成果物⑦）、見出しごとに約1,500字で頼む。
- 最後に必ず5つのチェックを通し、自分の言葉（体温）を上書きする。

**クリア条件：成果物⑥が完成し、序章の見出し1つ分の下書きを⑦で作れたら、第4章はクリアです。**

# 第6章 KDP登録の操作

## 1. 登録は「準備が9割」

原稿が書き上がったら、いよいよAmazonに登録します。
KDP（Kindle Direct Publishing）の登録画面は、項目が多く、初めての人は途中で手が止まりがちです。

でも安心してください。**入力する内容は、ここまでの章でほぼ全部できあがっています。**
この章では、それを「どの画面のどこに入れるか」を確認しながら、**成果物⑨：原稿・登録チェックリスト**を完成させます。

> ⚠️ **画面について**
> KDPの画面や項目名は、ときどき変更されます。本書と表示が違う場合は、**画面の表示とKDP公式ヘルプを優先**してください。迷ったときは、画面右上などにある「ヘルプ」から該当項目を検索できます。

### 全体の流れ（目安：合計2〜3時間）

```
STEP1 原稿を仕上げる（ファイル化）        … 60分
STEP2 KDPアカウントを作る                 … 15分
STEP3 税務情報・口座を登録する            … 30分
STEP4 本を登録する（3つのタブ）           … 60分
STEP5 審査を待つ → 公開                   … 最大72時間程度
```

一度に全部やる必要はありません。**STEP2〜3を先にやっておく**と、本の登録がスムーズです。

## 2. STEP1：原稿を仕上げる

### 原稿の形式
初めての方は、**Word（.docx）形式**がいちばん簡単です。
Googleドキュメントで書いた場合も、「ファイル → ダウンロード → Microsoft Word」で.docxにできます。

> 縦書きにしたい、レイアウトを細かく整えたい場合は、Amazonの無料ツール「Kindle Create」も使えます。最初の1冊は、横書きのWordで十分です。

### 原稿の最終チェック
- [ ] 見出し（章タイトル）に、Wordの「見出し1」「見出し2」スタイルを設定した（目次が自動で作れる）
- [ ] 目次を入れた
- [ ] 巻末に「著者プロフィール」と「読者特典の案内」を入れた（特典の作り方は第7章）
- [ ] 誤字脱字をチェックした（AIに「誤字脱字だけを指摘して」と頼むと便利）
- [ ] 実績の数字・年齢が、紹介文やプロフィールと同じ表記になっている
- [ ] 他人の文章・画像を無断で使っていない

## 3. STEP2：KDPアカウントを作る

1. 「Kindle ダイレクト・パブリッシング」で検索し、KDPの公式サイトを開く
2. Amazonアカウントでサインイン（普段の買い物用アカウントでOK）
3. 利用規約に同意する

> 💡 公式サイトかどうかは、アドレスが **kdp.amazon.co.jp** であることで確認してください。

## 4. STEP3：税務情報・口座を登録する

ここが、いちばん手が止まりやすいところです。落ち着いて進めてください。

### 著者情報・支払い情報
- 氏名・住所・電話番号
- 印税の振込先の**銀行口座**（第2章で確認した口座）

### 税務情報（タックスインタビュー）
Amazonはアメリカの会社のため、税務情報の入力が必要です。
画面の質問（タックスインタビュー）に答えていくと、必要な書類が自動で作成されます。

- 日本在住の個人の場合、質問に沿って「個人」「日本の居住者」などを選びます
- マイナンバーなど、日本の納税者番号の入力を求められることがあります
- 入力内容によって、アメリカで差し引かれる税率が変わります

> ⚠️ 税務の選択肢や必要な番号は変更されることがあります。**画面の説明とKDP公式ヘルプに従って**入力してください。判断に迷う場合は、税理士や税務署に相談してください。

## 5. STEP4：本を登録する（3つのタブ）

KDPの「本棚」から「＋電子書籍」を選ぶと、登録が始まります。
登録画面は、次の**3つのタブ**に分かれています。途中で「下書きとして保存」できるので、1タブずつ進めて大丈夫です。

### タブ①：電子書籍の詳細

| 項目 | 入れるもの | 出どころ |
|---|---|---|
| 言語 | 日本語 | − |
| 本のタイトル／サブタイトル | 決定したタイトル | 成果物⑧ |
| 著者 | 著者名（ペンネーム可） | 成果物⑧ |
| 内容紹介 | Amazon用の紹介文 | 成果物⑧ |
| 出版に関して必要な権利 | 「著作権を所有しており…」を選択 | − |
| 主な対象読者 | 該当する項目を選択 | − |
| カテゴリー | 本の内容に合うものを選択 | 成果物③ |
| キーワード | 読者が検索しそうな言葉（最大7つ） | 下のワーク |

**キーワードの考え方**
タイトルに入れなかった言葉を、ここに入れます。読者が実際に検索しそうな言葉を選んでください。

```
例：50代 起業／人生 やり直し／成功思考／中高年 副業／AI 活用／Kindle出版 初心者／再起
```

> ⚠️ 他の著者名・他の本のタイトル・「ベストセラー」などの言葉は、キーワードに入れないでください（ガイドライン違反になります）。

### タブ②：電子書籍のコンテンツ

| 項目 | やること |
|---|---|
| DRM（デジタル著作権管理） | 「適用する」を選ぶのが一般的（**公開後は変更できない**ので注意） |
| 原稿 | STEP1のWordファイルをアップロード |
| 表紙 | 第5章で作った表紙画像をアップロード（または表紙作成ツールを使う） |
| AI生成コンテンツ | AIの使用について質問に答える（下の説明を参照） |
| プレビュー | 「プレビューアーで確認」で、スマホ・タブレットでの見え方を確認 |

**AI生成コンテンツの申告について**
KDPでは、AIの使用について申告を求められます。KDPの説明では、おおむね次のように区別されています。

- **AI生成**：文章・画像などをAIが作ったもの → 申告が必要
- **AI支援**：自分で作ったものを、AIで編集・改善・アイデア出しに使ったもの → 申告は不要とされている

第4章の方法では、AIが下書きを作るため、**「AI生成」に当たる部分がある**可能性があります。迷った場合は正直に申告してください。
※区分や申告方法は変更されることがあります。**登録時に、画面の説明と公式ヘルプを必ず確認**してください。

**プレビューで確認すること**
- [ ] 目次からそれぞれの章に移動できる
- [ ] 文字化けや、変なところでの改ページがない
- [ ] 画像（使っている場合）がつぶれていない
- [ ] スマホの小さな画面でも読みやすい

### タブ③：電子書籍の価格設定

| 項目 | やること | 出どころ |
|---|---|---|
| KDPセレクト | 読み放題に登録するか選ぶ | 第5章の価格メモ |
| 出版地域 | 「すべての地域（全世界での権利）」が一般的 | − |
| ロイヤリティ | 35％／70％を選択（条件は画面で確認） | 第5章 |
| 価格 | 決めた価格を入力（Amazon.co.jp） | 第5章の価格メモ |

最後に「Kindle電子書籍を出版」を押せば、登録は完了です。

## 6. STEP5：審査を待つ → 公開

- 審査には、**最大72時間程度**かかることがあります（多くの場合はもっと早く終わります）
- 審査が終わると、登録したメールアドレスに通知が届きます
- 内容に問題がある場合も、メールで連絡が来ます。指示に従って修正し、再提出してください

### 公開されたら最初にやること
- [ ] Amazonで自分の本を検索し、表示を確認する
- [ ] 実際に購入（または読み放題で）して、スマホで読んでみる
- [ ] 巻末の特典案内が正しく表示されているか確認する
- [ ] 「Amazon著者セントラル」で著者ページを作る（成果物⑧の著者プロフィールを使う）

## 第6章のまとめ

- 登録は「準備が9割」。入れる中身は、第3章〜第5章でほぼできている。
- アカウント・税務・口座（STEP2〜3）を先に済ませておくと楽。
- 3つのタブ（詳細・コンテンツ・価格設定）を1つずつ進める。途中保存してOK。
- AIの使用は、画面の説明に従って正直に申告する。
- 画面が本書と違うときは、画面の表示と公式ヘルプを優先する。

**クリア条件：成果物⑨のチェックが全て埋まり、「出版」ボタンを押せたら、第6章はクリアです。**

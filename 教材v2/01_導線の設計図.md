# 第1章 導線の設計図

## 1. なぜ「導線」を最初に作るのか？

Kindle出版やBrain販売で手が止まる大きな理由のひとつは、**「書いてから売り方を考える」**ことです。
原稿を書き上げてから「どうやって売ろうか」「どこに案内しようか」と悩むと、手が止まりやすくなります。

本書の目的は、あなたの経験を読み物で終わらせず、**収益と読者とのつながりにつなげる仕組み**として形にすることです。
そのため、本文を書き始める前に「読者がどんな道筋で動くのか」という**導線の設計図**を先に持ってもらいます。

ここでは見本として、私（ハセジュン）が実際に組んでいる導線を公開します。

## 2. ハセジュン式・4段導線の見本

```
【第1段：認知・入口】
  Kindle電子書籍（またはBrain）
        ↓ （読者限定特典の案内）
【第2段：教育・信頼】
  公式LINE（7日間のステップ配信）
        ↓ （ワーク完走者限定の案内）
【第3段：体験・相談】
  無料Zoom説明会
        ↓ （希望する方のみ）
【第4段：本命・実践】
  3ヶ月集中「人生反撃」成功思考実践講座
```

それぞれの段には、明確な役割があります。

- **第1段（Kindle / Brain）**
  読者に気づきと、最初の一歩を踏み出すための**操作手順**を届ける。
- **第2段（公式LINE）**
  7日間のメッセージで、知識を「行動する習慣」に変えるきっかけを渡す。**売り込みはしない。**
- **第3段（Zoom説明会）**
  特典のワークシートを一緒に埋め、「次に何をすべきか」をはっきりさせる。
- **第4段（3ヶ月講座）**
  一人で進められる人は、本書だけで十分です。
  それでも「期限と伴走があったほうが進む」という人のために、週1回のZoom講義（全12回）と個別サポート（チャット＆相談）で、やり切るまで伴走する場として用意しています。

> ※本書は、上位講座に申し込まなくても**本書だけで成果物13点が完成する**ように作っています。

## 3. あなたの導線に書き換える（ワーク）

見本を、あなたのビジネスに当てはめます。

> **最初は2段で十分です。**
> 第3段・第4段がまだ無い人は、空欄のままで構いません。
> まずは「入口 → 公式LINE」の2段だけ決めれば、次の章へ進めます。

### 📝【成果物①】自分の導線図

| 段 | 何を | 価格 | 今ある／これから作る |
|---|---|---|---|
| ① 入口（集客） | | | |
| ② 特典 → 公式LINE | | 無料 | |
| ③ 中間（教育・体験） | | | |
| ④ ゴール（本命の提案） | | | |

**記入のヒント**

1. **入口**：最初に世に出す商品は？
   （例：Kindle出版、Brain教材）
2. **特典**：公式LINEに登録してもらうために何を渡す？
   （例：チェックリスト、AIプロンプト集、ワークブック ※第7章で作り方を解説）
3. **中間**：公式LINEのあと、どこへ案内する？
   （例：7日間のステップ配信のあと、無料Zoom説明会）
4. **ゴール**：最終的に、どんな人をどこへ案内する？
   （例：3ヶ月の伴走講座、個別コンサルティング）

## 第1章のまとめ

- 導線は「書いてから」ではなく、**最初に**決める。
- Kindle・Brainは、読者を案内するための**最初の入り口**。
- 最初は2段（入口 → 公式LINE）でよい。

**クリア条件：成果物①の「入口」と「特典→公式LINE」の2行が埋まったら、第1章はクリアです。**
